# 18.3 — "Copy to..." UI action

> Part of [Cross-assistant sync](plan.md) · spec: [../specs/phase-4-spec.md](../specs/phase-4-spec.md) §4

## Goal

Expose sync in the UI: a "Copy to..." action on an installed item (Installed
view and Dashboard) that lets the user pick a target assistant + scope
(+ project path when scope is `project`), runs `planSync`, shows the same
kind of preview the marketplace install pipeline already shows, and applies
on confirmation. Add a batch variant for multi-select.

This task must produce one commit containing only its changes.

## Steps

1. Add a "Copy to..." command (`aiSwissknife.syncArtifact`) invokable from
   `src/ui/installedView.ts`'s inline actions and from `src/ui/dashboard.ts`'s
   webview UI.
2. Target picker: assistant quick-pick (excluding the origin assistant),
   scope quick-pick (`global`/`project`), and — when `project` — the same
   workspace-folder picker already used elsewhere (`src/ui/workspacePicker.ts`).
3. Show the plan/preview (reuse the same preview rendering the install
   pipeline already has for `SupportedInstallPlan`/diagnostics), then apply
   through the existing `applyInstall` on confirmation.
4. Batch variant: multi-select in Installed view → same target picker once
   → per-item conflict resolution from 18.2 → aggregated outcome message
   (matching the existing batch-install aggregated-outcome style in
   `src/ui/availableView.ts`).

## Verification

- Run full test suite, lint, typecheck, build.
- Manually: sync a Kilo-installed agent to Claude Code project scope,
  confirm the translated file appears with correct format and the
  `ManagedInstallation` records the sync provenance; sync a batch of 2+
  items with one deliberate conflict and confirm skip/overwrite per item
  behaves as chosen.
