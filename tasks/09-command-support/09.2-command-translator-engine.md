# 09.2 — Command translator & install engine

> Part of [Command artifact support](plan.md) · spec: [../specs/phase-2-spec.md](../specs/phase-2-spec.md) · requires 09.1

## Goal

Implement `translateCommand`, `canonicalCommandHash`, and extend `planInstall` / `applyInstall` to handle `kind: 'command'`.

This task must produce one commit containing only its changes.

## Steps

1. Create `src/translator/command.ts`:
   - `translateCommand(source: CanonicalCommand, target: AssistantId): TranslationResult<CanonicalCommand>`
   - Translate fields losslessly for Claude and Kilo.
   - Return `overall: 'unsupported'` for unsupported assistants.

2. In `src/adapters/codec.ts`:
   - Implement `canonicalCommandHash(cmd: CanonicalCommand): string` (deterministic sha256).

3. Extend `src/engine/types.ts`:
   - Add `kind: 'command'` with `content: CanonicalCommand` to `PreparedInstall`.

4. Extend `src/engine/plan.ts` and `src/engine/apply.ts`:
   - Support `artifact.kind === 'command'`.
   - Single-file atomic install with backup, verification, rollback, and state tracking.

5. Add tests in `src/translator/command.test.ts` and `src/engine/install.test.ts`.

## Verification

- Run full test suite, lint, typecheck, build.
- Test Claude -> Kilo command translation and Kilo -> Claude command translation.
- Test atomic installation of a command and state persistence in `.ai-swissknife/state.json`.
