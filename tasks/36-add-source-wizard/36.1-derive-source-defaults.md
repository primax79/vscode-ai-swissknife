## Do

Create `src/sources/sourceDefaults.ts` (no `vscode` import) exporting:

- `validateLocation(type: SourceType, value: string): string | null` — error message or null. git types: HTTPS `https://host/...` or SSH (`git@host:org/repo(.git)`/`ssh://`); `remote-url`: `http(s)://` URL; `local-folder`: non-empty, not a URL.
- `deriveSourceDefaults(type, location): { id: string; name: string }` — id = lowercase slug of the last path segment (repo name without `.git`, folder basename, URL file name without extension), `[a-z0-9-]`, never empty (fallback `source`); name = humanized id (`team-skills` → `Team skills`).
