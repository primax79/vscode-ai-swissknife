# 14.2 — Promotion engine

> Part of [Discovery & promotion](plan.md) · spec: [../specs/phase-3-spec.md](../specs/phase-3-spec.md) · requires 14.1

## Goal

Implement `promoteObservedArtifact` in `src/engine/discovery.ts` that calculates the current disk content hash for an `ObservedArtifact` and records it as a `ManagedInstallation` in `state.json`.

This task must produce one commit containing only its changes.

## Steps

1. In `src/engine/discovery.ts`:
   - Implement `promoteObservedArtifact(observed: ObservedArtifact, sourceId?: string, homeRoot?: string): Promise<ManagedInstallation>`.
   - Reads disk artifact via appropriate adapter.
   - Computes canonical hash (`canonicalSkillHash`, `canonicalAgentHash`, `canonicalCommandHash`, `canonicalMcpServerHash`).
   - Appends `ManagedInstallation` to `state.json` via `readState` / `writeState`.
   - Returns the created `ManagedInstallation`.

2. Add unit tests in `src/engine/discovery.test.ts`.

## Verification

- Run full test suite, lint, typecheck, build.
- Test promotion of observed skills, agents, commands, and MCP servers to managed state.
