# 14.1 — Inventory scanner for unmanaged artifacts

> Part of [Discovery & promotion](plan.md) · spec: [../specs/phase-3-spec.md](../specs/phase-3-spec.md)

## Goal

Implement `scanInstalledInventory` in `src/engine/discovery.ts` that detects all artifacts on disk for each assistant and separates managed installations from unmanaged `ObservedArtifact`s.

This task must produce one commit containing only its changes.

## Steps

1. Create `src/engine/discovery.ts`:
   - `scanInstalledInventory(scope: Scope, projectRoot?: string, homeRoot?: string): Promise<{ managed: ManagedInstallation[]; observed: ObservedArtifact[] }>`.
   - Iterates through `claude-code`, `kilo-code`, `github-copilot`.
   - Uses `adapter.listSkills`, `listAgents`, `listCommands`, `listMcpServers`.
   - Compares with `state.json` installations.
   - Items not present in `state.json` are returned as `ObservedArtifact` with path, kind, assistant, scope, and `discoveredAt` timestamp.

2. Add unit tests in `src/engine/discovery.test.ts`.

## Verification

- Run full test suite, lint, typecheck, build.
- Test scanning of existing disk artifacts and distinguishing managed vs unmanaged.
