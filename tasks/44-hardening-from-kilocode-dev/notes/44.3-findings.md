## Conclusioni

1. **F3 è confermato e ha due livelli**: file sbagliato (Kilo ignora `mcp.json`) E forma della voce sbagliata (Kilo richiede `type: "local"` con `command` come **array** ed `environment`, oppure `type: "remote"` con `url`/`headers`; `stdio`/`args`/`env` vengono rifiutati come configurazione non valida).
2. **Correggere solo il percorso del file sarebbe pericoloso** (caso 3: una configurazione non valida impedisce a Kilo di avviarsi). La Fase 2 deve modificare insieme file e forma.
3. Il formato JSONC con commenti è accettato da Kilo, quindi il writer deve preservare i commenti (`jsonc-parser`).
4. Forme reali (sorgente: `kilocode-dev/packages/core/src/v1/config/mcp.ts`): local = `{type:"local", command:[cmd,...args], cwd?, environment?, env? (alias), enabled?, timeout?}`; remote = vedere la struttura `Remote` nello stesso file (i campi devono essere letti dall'esecutore, non tirati a indovinare).
