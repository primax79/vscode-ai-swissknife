# 44.1 — Harden git source resolution

One task, one commit. Security hygiene on an untrusted-input path (plan F1). Not a proven RCE; do not describe it as one in commit messages or code comments.

**Read first:** `../CONTEXT.md`, `plan.md` (F1), `src/sources/gitProcess.ts`, `src/sources/gitCustom.ts:80-135` and the other `runGit` users (`gitSingleItem.ts`, `gitMarketplace.ts`, and any other `runGit(` caller: `grep -rn "runGit(" src`), `src/sources/sourceDefaults.ts` (`validateLocation`, 36.1), `src/domain/registry.ts` (`fromDesiredSource`), `src/sources/remoteUrl.ts` (the HTTP fetch path).

## Do

1. **Validate at resolve time, not only in the wizard.** In every git resolver, before any `runGit`, call `validateLocation(type, source.url)`; on error throw a clear message (surfaces as the existing diagnostic group). Same for refs: `branch`, `tag`, `commit` must be non-empty, must not start with `-`, must not contain whitespace, control characters or `..`; commit additionally `/^[0-9a-f]{7,40}$/i`.
2. **`--` separators**: `git clone -- <url> <targetDir>`; `git checkout <ref> --`... where the ref is a revision (use `git checkout --detach <ref> --` or `git checkout <ref> --` as appropriate, keeping current behaviour); `git reset --hard <ref>` has no option ambiguity once the ref passed validation, still keep the validated value.
3. **Cache directory id**: after sanitising, reject ids that are empty, `.` or `..` (and any that end up starting with `.`), by throwing; additionally assert `path.resolve(targetDir)` starts with `path.resolve(baseCacheDir) + path.sep`. Never `rm -rf` a directory that fails this assertion.
4. **Protocol allow-list**: in `runGit` set `GIT_ALLOW_PROTOCOL` to `file:git:http:https:ssh` (what the validated URL shapes need; keep `file` only if a resolver or test clones local repos: check, do not assume) on the spawned process.
5. Do not change behaviour for valid sources: existing tests stay green untouched.

- New tests (`gitCustom.test.ts`, `gitSingleItem.test.ts`, `gitProcess.test.ts`): url `--upload-pack=x`, `-oProxyCommand=x`, `ext::sh -c x`, a url with a newline all rejected before git runs (spy that `runGit` is not called); refs `-x`, `a..b`, `a b` rejected; ids `.`, `..`, `` rejected and **no directory is removed** (create a sentinel dir/file and assert it still exists); valid https/ssh/scp URLs still resolve (existing fixtures); `runGit` env contains `GIT_ALLOW_PROTOCOL`.
- `npm test` whole suite green, `npm run build` clean. Tests use temp dirs only.
