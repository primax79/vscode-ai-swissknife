# 45.1 findings (PARTIAL, spike paused on 2026-10-08 by owner priority decision)

Executed against an isolated config dir (`CLAUDE_CONFIG_DIR=<repo>/.tmp/claude-spike`, since removed). The owner's real `~/.claude` was never written to (real list stayed at 10 plugins).

## Verified

1. **Isolation works**: `CLAUDE_CONFIG_DIR=<dir> claude plugin list --json` returns `[]` for a fresh dir while the real config lists 10. The spike (and the wrapper's tests, if an opt-in real-CLI smoke test is added) can run fully isolated.
2. **Binary**: `which claude` = `~/.local/bin/claude` -> symlink to `~/.local/share/claude/versions/2.1.287`; `claude --version` prints `2.1.287 (Claude Code)`. `~/.local/bin` is not on the default PATH of GUI-launched macOS apps, so the wrapper **must** try fallbacks (`~/.local/bin/claude`, `~/.claude/local/claude`, `/opt/homebrew/bin/claude`, `/usr/local/bin/claude`) besides PATH, and report what it searched.
3. **`claude plugin list --json`** (non-isolated): array of `{id, version, scope: user|project|local, enabled, installPath, installedAt, lastUpdated, projectPath?, projectEnabled?}`.
4. **`claude plugin install --scope <scope>`**: scopes `user | project | local`, default `user`; `-y/--yes` accepts a marketplace-declared command without prompting (the wrapper must never pass it).
5. **`claude plugin marketplace add <path>`**: works with a local directory, ~0.5 s, message "declared in user settings"; `marketplace list --json` returns `[{name, source: "directory"|..., path?, installLocation}]`.
6. **`claude plugin list --available --json`**: returns an object `{installed: [...], available: [{pluginId, name, description, marketplaceName, source}]}` (~2.1 s).
7. **`claude plugin details <id>`**: text output with the component inventory (skills/agents/hooks/MCP/LSP counts) and "Projected token cost: Always-on ~N tok" (no JSON mode confirmed yet).
