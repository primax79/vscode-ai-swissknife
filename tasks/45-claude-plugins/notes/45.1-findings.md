# Risultati di 45.1 (PARZIALI, spike messo in pausa il 2026-10-08 per decisione di priorità dell'owner)

Eseguito su una directory di configurazione isolata (`CLAUDE_CONFIG_DIR=<repo>/.tmp/claude-spike`, poi rimossa). La reale `~/.claude` dell'owner non è mai stata modificata (l'elenco reale è rimasto a 10 plugin).

## Verificato

1. **L'isolamento funziona**: `CLAUDE_CONFIG_DIR=<dir> claude plugin list --json` restituisce `[]` per una directory nuova mentre la configurazione reale elenca 10 plugin. Lo spike (e i test del wrapper, se viene aggiunto uno smoke test opzionale con la CLI reale) può girare in completo isolamento.
2. **Binario**: `which claude` = `~/.local/bin/claude` -> symlink a `~/.local/share/claude/versions/2.1.287`; `claude --version` stampa `2.1.287 (Claude Code)`. `~/.local/bin` non si trova nel PATH predefinito delle applicazioni macOS avviate dalla GUI, quindi il wrapper **deve** provare dei fallback (`~/.local/bin/claude`, `~/.claude/local/claude`, `/opt/homebrew/bin/claude`, `/usr/local/bin/claude`) oltre al PATH, e riportare dove ha cercato.
3. **`claude plugin list --json`** (non isolato): array di `{id, version, scope: user|project|local, enabled, installPath, installedAt, lastUpdated, projectPath?, projectEnabled?}`.
4. **`claude plugin install --scope <scope>`**: ambiti `user | project | local`, predefinito `user`; `-y/--yes` accetta un comando dichiarato dal marketplace senza chiedere conferma (il wrapper non deve mai passarlo).
5. **`claude plugin marketplace add <path>`**: funziona con una directory locale, ~0.5 s, messaggio "declared in user settings"; `marketplace list --json` restituisce `[{name, source: "directory"|..., path?, installLocation}]`.
6. **`claude plugin list --available --json`**: restituisce un oggetto `{installed: [...], available: [{pluginId, name, description, marketplaceName, source}]}` (~2.1 s).
7. **`claude plugin details <id>`**: output testuale con l'inventario dei componenti (conteggi di skills/agents/hooks/MCP/LSP) e "Projected token cost: Always-on ~N tok" (nessuna modalità JSON ancora confermata).

## Non ancora verificato (aperto alla ripresa dell'iniziativa)

Semantica degli ambiti con cwd / `--project`, comportamento di `enable`/`disable`/`update`/`uninstall` per ambito, modalità di errore non interattive e codici di uscita, quale file di impostazioni viene toccato da ciascun comando, `--json` `shownCommand.sha256` per le sorgenti comando, `details --json`, tempistiche di `update`, versione minima della CLI.
