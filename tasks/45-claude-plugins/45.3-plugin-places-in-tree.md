# 45.3 — Plugin places in the Installed tree and Dashboard (read-only)

One task, one commit. Depends on 45.2 and on 40.1 (place model), 40.2 (renderer), 40.4 (scope icons). Assumptions CP-Q3 / CP-Q4 of the plan apply until the owner changes them.

**Read first:** `plan.md`, `src/engine/claudeCli.ts` (45.2), `src/engine/installedTree.ts` (40.1), `src/ui/dashboard.ts` and the sidebar `installedView.ts` for the Claude environment, `src/ui/scopeIcons.ts`.

## Do

1. Extend the place model with kind `plugin` (Claude only): a plugin install is a **place** (assistant Claude, scope user->Global / project->Workspace / local->Workspace (private) with its own icon variant and tooltip, state enabled | disabled | update-available if the CLI reports it) whose **children** are the plugin's components from `details` (skills, agents, commands, hooks, MCP, with counts) and whose parent row shows the **always-on token cost** (a small badge, e.g. "~1,000 tok").
2. Load via `ClaudeCli` asynchronously (the tree renders first, plugins appear when `list --json` returns, with a loading line); failures show one muted line "Claude plugins unavailable: <reason>" (CLI missing/old), never an error toast.
3. **Duplicate detection**: for each plugin skill/agent/command, flag a loose artifact of the same kind and name in the same Claude environment (Global/Workspace); show a "duplicate" marker with a tooltip naming both locations. Detection only, no action.
4. Sidebar (Claude view) and Dashboard (Installed tree) both show it; read-only: row click opens the detail panel with id, marketplace, version, commit, install path, scope, components, token cost.
5. Totals: header stats include a "Plugins" count; the filters (40.5) get the kind pill "Plugins".

## Verification

With a mocked `ClaudeCli` returning the recorded fixtures: one parent row per plugin install with the right scope icon/badge, children from details, token badge; a plugin installed at two scopes yields two places; disabled one muted; CLI-missing path shows the muted line and nothing else breaks; a loose skill named like a plugin skill raises the duplicate marker. `npm test` green, `npm run build` clean. Manual with the real CLI: the 10 plugins of the owner's machine appear.
