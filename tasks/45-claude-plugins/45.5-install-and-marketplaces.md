# 45.5 — Installazione dai marketplace, sincronizzazione dei marketplace, scelta della modalità di installazione

Un task, un commit (se cresce oltre tale dimensione, suddividerlo in base ai risultati e segnalarlo). Dipende da 45.4. L'ipotesi CP-Q5 si applica finché l'owner non la modifica.

**Read first:** `plan.md`, `notes/45.1-findings.md` (punto 6: installazioni da sorgente comando), `src/engine/claudeCli.ts`, `src/sources/gitMarketplace.ts` (la nostra sorgente Claude-marketplace), il flusso di installazione unificato dell'iniziativa 37 (`installItems`) e il flusso "install elsewhere" di 41.

## Cosa fare

1. **Installare un plugin nativamente**: dall'elenco di `listAvailablePlugins()` (QuickPick con marketplace, plugin, descrizione, versione) -> scegliere l'ambito (Global / Workspace / Workspace (private); solo Global senza un workspace) -> `claude plugin install <plugin@marketplace> --scope ...`. Se il marketplace dichiara un comando di installazione la CLI riporta `shownCommand` e il relativo sha256: mostrarli entrambi in una modale; solo una conferma esplicita "Install" procede, passando `--accept-command <that sha256>` esattamente per quel comando (mai `-y`).
2. **Sincronizzazione dei marketplace**: per una sorgente di ai-swissknife di tipo `git-marketplace` che sia un marketplace Claude, aggiungere l'azione "Register as Claude marketplace" (`claude plugin marketplace add <url>`) e, per quelli già registrati, "Update marketplace" (`marketplace update`); le righe in Sources mostrano un piccolo indicatore quando il repository è presente anche come marketplace Claude in `marketplace list`.
3. **Modalità di installazione** (CP-Q5): quando il flusso di installazione di 37 / 41 ha come target Claude con un artefatto che appartiene a un plugin di un marketplace Claude, offrire "As native plugin (recommended)" oppure "As loose artifacts"; gli altri assistenti ricevono solo artefatti sciolti. La scelta appare nel riepilogo finale del flusso, non come prompt aggiuntivo prima di esso.
4. Tutti gli errori vengono riportati come in 45.4.

## Verification

Mock di `ClaudeCli`: l'installazione costruisce il comando corretto per ambito; un plugin con sorgente comando mostra la modale e passa lo sha solo dopo la conferma (annulla = nessuna chiamata); l'aggiunta/aggiornamento del marketplace viene invocata con l'URL della sorgente; la scelta della modalità appare solo per i target Claude di artefatti provenienti da un marketplace. `npm test` verde, `npm run build` pulito. Manuale: registrare la sorgente `agentic-coding-kit` come marketplace Claude e installare nativamente uno dei suoi plugin in una directory di configurazione isolata.
