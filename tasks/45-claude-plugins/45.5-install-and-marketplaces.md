# 45.5 — Install from marketplaces, marketplace sync, install-mode choice

One task, one commit (if it grows past that, split per the findings and report). Depends on 45.4. Assumption CP-Q5 applies until the owner changes it.

**Read first:** `plan.md`, `notes/45.1-findings.md` (item 6: command-source installs), `src/engine/claudeCli.ts`, `src/sources/gitMarketplace.ts` (our Claude-marketplace source), the unified install flow of initiative 37 (`installItems`) and the "install elsewhere" flow of 41.

## Do

1. **Install a plugin natively**: from the list of `listAvailablePlugins()` (QuickPick with marketplace, plugin, description, version) -> choose scope (Global / Workspace / Workspace (private); only Global without a workspace) -> `claude plugin install <plugin@marketplace> --scope ...`. If the marketplace declares an install command the CLI reports `shownCommand` and its sha256: show both in a modal; only an explicit "Install" confirmation proceeds, passing `--accept-command <that sha256>` for exactly that command (never `-y`).
2. **Marketplace sync**: for an ai-swissknife source of type `git-marketplace` that is a Claude marketplace, add the action "Register as Claude marketplace" (`claude plugin marketplace add <url>`) and, for already registered ones, "Update marketplace" (`marketplace update`); Sources rows show a small marker when the repository is also a Claude marketplace in `marketplace list`.
3. **Install mode** (CP-Q5): when the install flow of 37 / 41 targets Claude with an artifact that belongs to a Claude marketplace plugin, offer "As native plugin (recommended)" or "As loose artifacts"; other assistants only get loose artifacts. The choice appears in the final summary of the flow, not as an extra prompt before it.
4. All failures reported as in 45.4.
