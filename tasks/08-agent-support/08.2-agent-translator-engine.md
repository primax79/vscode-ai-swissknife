# 08.2 — Agent translator & install engine

> Part of [Agent artifact support](plan.md) · spec: [../specs/phase-2-spec.md](../specs/phase-2-spec.md) · requires 08.1

## Goal

Implement `translateAgent` translating between Claude's `tools` array and Kilo's `mode` + `permission` block, and extend `planInstall` / `applyInstall` to handle `kind: 'agent'`.

This task must produce one commit containing only its changes.

## Steps

1. Create `src/translator/agent.ts`:
   - `translateAgent(source: CanonicalAgent, target: AssistantId): TranslationResult<CanonicalAgent>`
   - Map `tools` array to Kilo `permission` block (`read`, `edit`, `bash`, `skill`, `webfetch`, `mcp`).
   - Map Kilo `permission` block to Claude `tools` array.
   - Preserve `body` markdown and `extraFields`.
   - Issue `TranslationDiagnostic` for unmapped custom tools.

2. Extend `src/engine/plan.ts`:
   - Support `artifact.kind === 'agent'`.
   - Resolve agent content from source via `resolveArtifactContent`.
   - Compute proposed agent file (single markdown file with content hash).
   - Inspect target agent file on disk for conflict detection.

3. Extend `src/engine/apply.ts`:
   - Handle single-file atomic swap for agents (write staging file -> swap -> verify -> update `state.json`).

4. Add unit tests in `src/translator/agent.test.ts` and `src/engine/install.test.ts`.

## Verification

- Run full test suite, lint, typecheck, build.
- Test Claude -> Kilo agent translation and Kilo -> Claude agent translation.
- Test atomic installation of an agent and state persistence.
