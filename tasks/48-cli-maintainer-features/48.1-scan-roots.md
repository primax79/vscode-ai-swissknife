# 48.1 — Multi-root scanning with ignore rules (engine + CLI option)

One task, one commit. Wishlist item 5 (`specs/cli-wishlist-comparison.md`): apply list/status to a set of workspace roots in one call, skipping node_modules, worktrees, caches and archive folders. Decided by the architect (delegated by the owner, 2026-10-09). Depends on 46.1 (CLI, merged). **Do not edit AGENTS.md** (Kilo's runs are denied that edit; the architect documents afterwards).

**Read first:** `plan.md`, `../46-cli-access/plan.md` (the CLI contract), `src/cli/{definitions,commands,main,types}.ts`, `src/engine/discovery.ts` (`scanInstalledInventory(scope, projectRoot, homeRoot)`), `src/domain/registry.ts` (`manifestPath`: workspace manifests live at `.vscode/ai-swissknife/manifest.json` or the legacy `.ai-swissknife/manifest.json`), `src/adapters/{kilo,claude}.ts` (project dirs `.kilo`, `.kilocode`, `.claude`).

## Do

1. **Engine** `src/engine/scanRoots.ts` (no `vscode` import): `findWorkspaces(roots: string[], options?: { maxDepth?: number; ignore?: string[]; extraIgnore?: string[] })` returns the directories under the roots that look like workspaces: they contain `.claude/`, `.kilo/`, `.kilocode/`, `.vscode/ai-swissknife/` or `.ai-swissknife/`. Rules: breadth-first, **default maxDepth 4**, **never follows symlinks**, stops descending into a directory once it is a workspace (nested workspaces are found only at their own level: do not descend into a found workspace's children *except* to keep searching sibling directories), skips by directory name (defaults: `node_modules`, `.git`, `.kilo/worktrees` (path segment pair), `worktrees`, `cache`, `.cache`, `dist`, `out`, `build`, `target`, `_attic`, `_deprecated`, `old`, `very_old`, `.tmp`, `__pycache__`, `venv`, `.venv`); `ignore` replaces the defaults, `extraIgnore` adds to them. Unreadable directories are skipped and reported in a `skipped` list with the reason, never throwing. Returns `{ workspaces: string[], skipped: { path, reason }[] }` with stable (sorted) order.
2. **Aggregation** `scanInventoryAcrossRoots(roots, { assistants, scopes, homeRoot, options })`: calls `scanInstalledInventory` for the Global scope **once** and for the Workspace scope of every found workspace, tagging each item with `workspace` (absolute path, or `null` for Global) so identical items in different workspaces stay distinguishable (the item key of the CLI gets the workspace folder name appended only when more than one workspace is scanned, e.g. `claude-code:project:skill:foo@my-repo`; single-workspace keys are unchanged).
3. **CLI**: global option `--roots <dirs...>` (repeatable) and `--max-depth <n>`, `--ignore <names...>`, `--extra-ignore <names...>`; honoured by `installed` and `updates` (and `item` resolution of workspace-suffixed keys). With `--roots`, `--workspace` is ignored for those commands (state it in `--help`). Output of `installed` gains `workspace` per item; add a `workspaces` array and the `skipped` list to the JSON **only when `--roots` is used** (existing output shape unchanged otherwise). Update the command definitions table so `describe` shows the new options.
4. Read-only: the scan writes nothing.
