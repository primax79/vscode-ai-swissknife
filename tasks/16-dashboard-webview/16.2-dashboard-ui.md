# 16.2 — Dashboard UI with search, filters, and actions

> Part of [Management dashboard webview](plan.md) · spec: [../specs/phase-3-spec.md](../specs/phase-3-spec.md) · requires 16.1

## Goal

Build a clean, responsive HTML/CSS/JS interface for the Dashboard webview using VS Code theme tokens.

This task must produce one commit containing only its changes.

## Steps

1. In `src/ui/dashboard.ts`:
   - Generate HTML with:
     - Header bar with title, search input, and action buttons ("Refresh", "Add Source", "Check Drift").
     - Metric cards (Total Installed, Updates Available, Locally Modified, Unmanaged).
     - Kind filter tabs (All, Skills, Agents, Commands, MCP Servers).
     - Table / Card grid of items showing Assistant, Scope, Kind, Name, Description, Drift Status Badge, and Action buttons (Install / Update / Promote / Remove).

2. Add unit tests in `src/ui/ui.test.ts`.

## Verification

- Run full test suite, lint, typecheck, build.
