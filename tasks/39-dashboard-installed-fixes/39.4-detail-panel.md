# 39.4 — Detail panel that can be understood

One task, one commit. Depends on 39.1. 39.2 puts its new actions into the bar defined here, so run 39.4 before 39.2.  Q3 is decided: labels in the detail panel, icon-only in the compact tree rows.

**Read first:** `plan.md` finding 5 and Q3, `src/ui/dashboard.ts`: `showItemDetail` server side `:480-556` (origin text at `:525` and `:546`), panel markup `:1210-1228`, client `itemDetail` handler `:2145-2195`, `src/engine/discovery.ts` (`ObservedArtifact.match` / `candidates`), `src/engine/drift.ts` (`DriftReport`), `src/ui/scopeIcons.ts` and `getAssistantIconPath`.

## Problem (owner screenshot, "incomprensibile")

For an unmanaged skill the panel shows `ORIGIN: local, no known origin`, then an unlabeled `⇄` button alone in its own block, a divider, then an unlabeled `⇧` button. Causes in code:

- Origin for any observed item is the hard-coded string `'local, no known origin'` (`dashboard.ts:546`), even when the same item's row says "differs from gcube-ai-toolkit" (its `obs.match`/`obs.candidates` are ignored). The panel contradicts the table.
- The `⇄` (Diff) lives in a separate `#diffSection` with no label or context, and the `⇧` (Promote) in `#detailActions`: two icon-only buttons in two unrelated blocks, nothing says what each does or to what.
- The panel does not say where the item is (assistant, scope, path) or what its state is in words.

## Do

Restructure the panel into one readable layout, top to bottom:

1. **Header**: kind pill, name, assistant icon + scope icon (40.4 if present, else existing helpers; label "Workspace"/"Global").
2. **Status line** in words, same badge as the row (shared with 39.3's helper when it lands): e.g. "Unmanaged · differs from gcube-ai-toolkit", "Managed · update available".
3. **Origin**, computed, never hard-coded: managed → `<source>@<short commit>` (as today); unmanaged with candidates → "Matches registered source `<source>` — identical" / "— differs (your copy was changed or is a different version)"; if several candidates list them; no candidate → "Local only: not found in any registered source".
4. **Location**: the path on disk (click opens the file via the existing Preview handler).
5. **One action bar** containing every action (Diff included — remove the separate `#diffSection`), each button with icon **and** short text label per Q3, grouped (primary: Promote / Update; secondary: Preview, Diff, Copy, Move, Edit; destructive last, visually separated). Buttons that do not apply are not rendered; Diff is shown whenever a comparison exists (managed modified, unmanaged `different`).
6. "Installed also in" (cross-framework) is also computed for unmanaged items (it is `[]` today, `:548`); reuse `findRelatedInstallations` over managed + observed, or state explicitly in the Final Report why not.

## Non-goals

No new actions (39.2), no badge wording change (39.3), no change to the table.
