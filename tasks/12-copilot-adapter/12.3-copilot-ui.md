# 12.3 — Engine & UI integration for GitHub Copilot

> Part of [GitHub Copilot adapter](plan.md) · spec: [../specs/phase-2-spec.md](../specs/phase-2-spec.md) · requires 12.2

## Goal

Expose GitHub Copilot (`github-copilot`) in the assistant selection UI and support end-to-end installation across all artifact kinds into Copilot paths.

This task must produce one commit containing only its changes.

## Steps

1. In `src/engine/apply.ts`:
   - Instantiate and dispatch `CopilotAdapter` when `targetAssistant === 'github-copilot'`.

2. In `src/ui/availableView.ts`:
   - Add `github-copilot` to the assistant selection quick-pick.
   - Wire `copilotAdapter`.

3. Update `src/engine/install.test.ts` and `src/ui/ui.test.ts`.

## Verification

- Run full test suite, lint, typecheck, build.
- Test install of skills, agents, commands, and MCP servers into GitHub Copilot paths end-to-end.
