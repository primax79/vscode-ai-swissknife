# 41.2 — Pulsante di riga, selettore delle posizioni, passaggio al flusso di installazione

Un task, un commit. Dipende da 41.1, 37.2 e 40.2. La questione Q1 del piano è decisa: un elemento non gestito ma differente installa la versione della sorgente, e il titolo dichiara "from <source>".

**Read first:** `plan.md`, `src/engine/missingPlaces.ts` (41.1), `src/ui/availableView.ts` (il flusso unificato `installItems` di 37.2, `resolveArtifactById :698`, `doInstallArtifact :714`), `src/ui/installedView.ts:557-621` (`doSyncItem`, il fallback per copia locale), `src/ui/dashboard.ts` (switch dei messaggi `:126-340`, le righe dell'albero di 40.2, l'action layer di 31), `src/ui/scopeIcons.ts` (40.4), `getAssistantIconPath`.

## Cosa fare

1. Righe della Dashboard (riga dell'oggetto quando supportata da una sorgente, righe delle posizioni sempre): pulsante solo icona "Install to other environments", che invia `{ command: 'installElsewhere', key }`; effettuare l'escape degli id con gli helper esistenti.
2. Handler → metodo del provider `installElsewhere(key)`: `resolveOrigin`; se `candidates`, QuickPick per scegliere quale sorgente; calcolare `computeMissingPlaces`; mostrare il **selettore a selezione multipla** (elementi: icona dell'assistente + icona dell'ambito + etichette, quelli non supportati disabilitati con il relativo motivo, nulla preselezionato; titolo "Install <name> from <source>" oppure "Copy <name> from <assistant> (<scope>)" per il fallback locale). Offerta vuota → messaggio informativo "Already installed everywhere supported".
3. Origine da sorgente → risolvere l'elemento del catalogo con `resolveArtifactById`, quindi invocare il flusso di 37.2 con l'insieme `(assistant, scope)` scelto preselezionato, in modo che l'utente arrivi direttamente al riepilogo finale (Preview / Install / Overwrite); non chiedere di nuovo assistenti/ambito. Origine locale → stesso flusso tramite `planSync` per ciascun target scelto (riutilizzare la pianificazione di `doSyncItem`, non i suoi prompt).
4. Dopo il completamento con successo aggiornare Installed e la Dashboard (callback di refresh esistenti).

## Non-obiettivi

Nessuna modifica a `Copy to...`/`Move`, ai pulsanti di installazione della scheda Sources o alla semantica del motore.
