# 11.1 — Claude & Kilo marketplace manifest resolver

> Part of [Marketplace sources resolver](plan.md) · spec: [../specs/phase-2-spec.md](../specs/phase-2-spec.md)

## Goal

Implement `resolveGitMarketplace` in `src/sources/gitMarketplace.ts` that clones/fetches marketplace git repositories, parses `.claude-plugin/marketplace.json` or `marketplace-skills.json`, and discovers skills, agents, commands, and MCPs within each registered plugin.

This task must produce one commit containing only its changes.

## Steps

1. Create `src/sources/gitMarketplace.ts`:
   - `gitMarketplaceMutex`: KeyedMutex for cache synchronization.
   - `resolveGitMarketplace(source: Source, opts?: GitCustomResolveOptions): Promise<SourceResolution>`.
   - Clones/fetches repo, checks out requested ref (commit/tag/branch/default).
   - Detects marketplace manifest:
     - `.claude-plugin/marketplace.json` or `marketplace.json` (Claude plugin format).
     - `marketplace-skills.json` (Kilo feed format).
   - For each plugin entry in manifest:
     - Reads plugin directory or target path.
     - Detects skills, agents, commands, and MCP servers inside the plugin folder.
     - Constructs `Package` items and collects `DetectionDiagnostic`s.

2. Add unit tests in `src/sources/gitMarketplace.test.ts`.

## Verification

- Run full test suite, lint, typecheck, build.
- Test resolution of marketplace repository with multiple plugins and nested artifacts.
