# 11.2 — Marketplace content resolution & install engine

> Part of [Marketplace sources resolver](plan.md) · spec: [../specs/phase-2-spec.md](../specs/phase-2-spec.md) · requires 11.1

## Goal

Implement `resolveArtifactContent` for `git-marketplace` sources across all artifact kinds (`skill`, `agent`, `command`, `mcp-server`), and wire into `planInstall`.

This task must produce one commit containing only its changes.

## Steps

1. In `src/sources/gitMarketplace.ts`:
   - Implement `resolveArtifactContent(source: Source, pkg: Package, artifact: Artifact, opts?: GitCustomResolveOptions): Promise<ResolvedArtifact<...>>`.
   - Acquire cache directory lock under `gitMarketplaceMutex`.
   - Checkout `pkg.version.commit`.
   - Resolve artifact content based on `artifact.kind`.

2. Wire `resolveGitMarketplace` and `resolveArtifactContent` into `src/engine/plan.ts`.

3. Add unit tests for content resolution and installation of marketplace artifacts in `src/engine/install.test.ts`.

## Verification

- Run full test suite, lint, typecheck, build.
- Test plan and apply for a skill, agent, command, and MCP server resolved from a marketplace source.
