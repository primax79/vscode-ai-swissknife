## Definizioni

- **Favorite** = l'esistente Recommend / Unrecommend per il workspace (`recommendForWorkspace` `$(star-empty)` / `unrecommendForWorkspace` `$(star-full)`); l'icona riflette lo stato (stella vuota / stella piena). Confermato dall'owner (2026-10-08): "Preferiti" = Recommend / Unrecommend per il workspace.
- Terzetto inline per elemento gestito (`installedInstallation[:status][:recommended]`), in questo ordine fisso: **Favorite**, **Update** (abilitato solo per `update-available` e `modified-and-update-available`, disabilitato altrimenti), **Uninstall** (sempre abilitato; apre la modale Remove soft/hard di 39.2).
- Elemento non gestito (`observedArtifactItem[:one|:many][:different|:identical]`): il terzetto dell'owner non si applica, quindi il suo terzetto inline fisso (confermato dall'owner, 2026-10-08) è **Promote** (abilitato), **Diff** (abilitato solo quando differisce da una sorgente), **Remove** (modale soft/hard di 39.2). Nessuno slot Favorite/Update sulle righe non gestite.
- **Menu contestuale** (clic destro), raggruppato, mostra ogni altra azione *applicabile allo stato*, mai voci disabilitate di riempimento: Preview, Diff (gestito: solo quando modificato), Edit, Copy to..., Move to..., Install to other environments (41), Reveal in File Explorer, Copy path, Open source repository (42.2), Promote/Unmanage quando applicabili; le voci relative al ripristino non si trovano qui.
- Le righe Available (catalogo) e sorgente sono fuori ambito per questo task.

## Cosa fare

1. `package.json`: `enablement` dei comandi per Update e Diff (chiavi di contesto derivate da `viewItem`, ad es. `viewItem =~ /:(update-available|modified-and-update-available)/`) in modo che il terzetto inline mantenga le proprie posizioni; le voci inline usano `group: inline@1..3` nell'ordine indicato sopra; spostare tutto il resto da `inline` ai gruppi `view/item/context` con predicati `when` appropriati.
2. **Righe della Dashboard (solo icona):** lo stesso terzetto per appartenenza, con la stessa logica abilitato/disabilitato, più un pulsante di overflow `...` che apre un semplice menu a tendina con l'insieme del menu contestuale. Il pannello di dettaglio mantiene l'insieme completo con icona + etichetta (39.4).
3. Aggiungere in coda a `specs/actions-study.md` sotto "What shipped" la tabella risultante azione x stato x superficie.
