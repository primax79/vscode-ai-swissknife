# 42.2 — Navigation helpers

One task, one commit. No engine change.

**Read first:** `plan.md`, `package.json` (command and menu patterns), `src/ui/installedView.ts` (how items expose `installation.path` / `observed.path`), `src/ui/dashboard.ts` (message switch, detail panel action area), `src/domain/types.ts` (`sourceId`, `sourceRevision`, source `url`).

## Do

Three small commands, each usable from the sidebar (context menu, not inline) and from the Dashboard (detail panel action bar and the row overflow menu of 42.3; until 42.3 exists, the detail bar only):

- `aiSwissknife.revealInOS` ("Reveal in File Explorer" / Finder): `vscode.commands.executeCommand('revealFileInOS', uri)` on the item path.
- `aiSwissknife.copyPath`: `vscode.env.clipboard.writeText(path)` plus a status-bar confirmation.
- `aiSwissknife.openSourceRepo` ("Open Source Repository"): for items with a source, open the source's git URL (and, when the revision commit is known and the host is GitHub/GitLab/Gitea-style, the commit URL) with `vscode.env.openExternal`; hidden when the item has no source or the source is a local folder.

Icons: `$(folder-opened)`, `$(copy)`, `$(link-external)`. Detail-panel buttons carry icon + short label; compact rows are icon-only.

## Verification

`ui.test.ts`: each command calls the right vscode API with the item's path / URL (spies); `openSourceRepo` not offered for local-folder or no-source items; Dashboard messages route to the same handlers. `npm test` green, `npm run build` clean.
