# 10.1 — CanonicalMcpServer model and Claude/Kilo MCP config adapters

> Part of [MCP-server artifact support](plan.md) · spec: [../specs/phase-2-spec.md](../specs/phase-2-spec.md)

## Goal

Add the canonical `CanonicalMcpServer` model and implement reading, writing, and merging MCP server configurations in `ClaudeAdapter` and `KiloAdapter`.

This task must produce one commit containing only its changes.

## Steps

1. Define `CanonicalMcpServer` in `src/adapters/types.ts`:
```ts
export interface CanonicalMcpServer {
  id: string;
  type: 'stdio' | 'http' | 'sse';
  command?: string;
  args?: string[];
  url?: string;
  env?: Record<string, string>;
  headers?: Record<string, string>;
  extraFields?: Record<string, unknown>;
}
```

2. Implement MCP adapter methods on `Adapter`:
   - `mcpConfigPath(loc: LocationRef): string`
   - `readMcpServer(id: string, loc: LocationRef): Promise<CanonicalMcpServer | null>`
   - `writeMcpServer(server: CanonicalMcpServer, loc: LocationRef): Promise<void>`
   - `listMcpServers(loc: LocationRef): Promise<string[]>`

3. Implement in `ClaudeAdapter` (`src/adapters/claude.ts`):
   - `mcpConfigPath(loc)`: `.mcp.json` (project) or `~/.claude/settings.json` (global).
   - Format: `{ "mcpServers": { "<id>": { "command": "...", "args": [...], "env": {...}, "url": "..." } } }`.

4. Implement in `KiloAdapter` (`src/adapters/kilo.ts`):
   - `mcpConfigPath(loc)`: `.kilo/mcp.json` (project) or `~/.config/kilo/mcp.json` (global).
   - Format: `{ "mcp": { "<id>": { "type": "stdio", "command": "...", "args": [...], "env": {...} } } }` (or `{ "mcpServers": ... }`).

5. Add unit tests in `src/adapters/claude.test.ts` and `src/adapters/kilo.test.ts`.

## Verification

- Run full test suite, lint, typecheck, build.
- Test round-trip serialization and reading of stdio and http/sse MCP servers.
- Prove merge preserves existing unmanaged servers in the config file.
