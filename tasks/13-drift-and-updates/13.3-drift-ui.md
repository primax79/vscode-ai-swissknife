# 13.3 — UI status indicators & update action

> Part of [Drift & update detection](plan.md) · spec: [../specs/phase-3-spec.md](../specs/phase-3-spec.md) · requires 13.2

## Goal

Surface drift statuses in the **Installed** view with distinct codicons and tooltips, and provide `AI Swissknife: Check for Updates` and `AI Swissknife: Update Item` commands.

This task must produce one commit containing only its changes.

## Steps

1. In `src/ui/installedView.ts`:
   - Cache `DriftReport` for each installed item.
   - Status codicons:
     - `up-to-date`: `$(pass)` or `$(check)`
     - `modified-locally`: `$(diff-modified)`
     - `update-available`: `$(cloud-download)` / `$(arrow-circle-up)`
     - `modified-and-update-available`: `$(warning)`
     - `missing-on-disk`: `$(error)` / `$(trash)`
   - Add `updateInstallation(item)`: triggers planInstall & applyInstall with latest content.

2. In `package.json`:
   - Add commands:
     - `aiSwissknife.checkDrift` ("Check Drift / Updates")
     - `aiSwissknife.updateItem` ("Update to Latest")
   - Bind inline actions on `installedInstallation`.

3. Add unit tests in `src/ui/ui.test.ts`.

## Verification

- Run full test suite, lint, typecheck, build.
- Verify status badges in Installed view and successful execution of update workflow.
