3. Does the assistant expose a **native disable** mechanism for each kind (Claude `disabledMcpServers`, skill/agent disable, Kilo config `disabled` fields)? Cite the source or doc line.
4. Does a file watcher in the tool react to the move (Kilo)? Any crash or noisy warning when an item vanishes from the active dir at runtime?
