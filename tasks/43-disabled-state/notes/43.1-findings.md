# Risultati dello spike 43.1 (2026-10-09, architetto, Kilo 7.4.5 reale)

Metodo: `HOME` isolata (`XDG_CONFIG_HOME` vuota) e un progetto temporaneo; fixture con un **controllo** nella directory attiva, il layout **fratello** A (`<root>/_disabled/<kind>/<name>`) e il layout **interno** C (`<active dir>/_disabled/<name>`); skill elencate con `kilo debug skill`, agent e command con `kilo debug config`. Directory temporanee rimosse al termine; la configurazione reale dell'owner non è stata toccata.

## Non verificato (esplicitamente)

- **Claude Code**: non è stato trovato alcun comando di elenco non interattivo che eviti di usare la reale directory `~/.claude` dell'owner e una sessione autenticata; il comportamento per una cartella sorella `.claude/_disabled/` è **unverified**. Aspettativa in base alle root di scansione documentate (solo `.claude/{skills,agents,commands}`): non caricato. Da confermare con una verifica interattiva (Developer host o elenco manuale `/skills`) prima che l'adapter Claude abiliti la funzionalità; fino ad allora l'adapter Claude può essere rilasciato dietro il flag unverified oppure usare il layout di fallback B.
- **Codex CLI, Gemini CLI, GitHub Copilot**: non testati; i rispettivi adapter restituiscono "disable unsupported" finché non saranno verificati.
- Reazione dei file watcher di Kilo allo spostamento: non osservata (non è stata usata alcuna sessione a lunga esecuzione).

## Decisione

Viene adottato il layout A (D-Q1 a) con l'hook per singolo assistente `getDisabledPath` in modo che qualsiasi assistente possa passare al layout B (`.ai-swissknife/_disabled/<assistant>/<kind>/<name>`) senza toccare il motore. Kilo è validato; gli altri restano disabilitati per impostazione predefinita finché non vengono verificati.
