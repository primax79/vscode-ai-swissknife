# 43.1 spike findings (2026-10-09, architect, real Kilo 7.4.5)

Method: isolated `HOME` (empty `XDG_CONFIG_HOME`) and a temp project; fixtures with a **control** in the active directory, the **sibling** layout A (`<root>/_disabled/<kind>/<name>`) and the **inside** layout C (`<active dir>/_disabled/<name>`); skills listed with `kilo debug skill`, agents and commands with `kilo debug config`. Temp dirs removed afterwards; the owner's real config was not touched.

## Kilo Code (verified)

| Kind | Scope / root scanned | Control (active dir) | **Sibling `_disabled/<kind>/` (layout A)** | Inside `_disabled/` (layout C) |
| --- | --- | --- | --- | --- |
| skill | global `~/.kilo/skills` | loaded | **not loaded** | loaded |
| skill | global `~/.claude/skills` (scanned by Kilo) | loaded | **not loaded** (`~/.claude/_disabled/skills`) | loaded |
| skill | project `.kilo/skills` | loaded | **not loaded** | loaded |
| skill | project `.claude/skills` (scanned by Kilo) | loaded | **not loaded** | loaded |

| command | global `~/.kilo/commands`, project `.kilo/commands` | loaded | **not loaded** | loaded |

**Conclusion for Kilo: layout A works** for skills, agents and commands at both scopes and for both roots Kilo scans; layout C is confirmed unusable (recursive discovery), as predicted from the source globs.

## Not verified (explicitly)

- **Claude Code**: no non-interactive listing was found that avoids using the owner's real `~/.claude` and a logged-in session; behaviour for a sibling `.claude/_disabled/` is **unverified**. Expectation from the documented scan roots (`.claude/{skills,agents,commands}` only): not loaded. To be confirmed in an interactive check (Developer host or a manual `/skills` listing) before the Claude adapter enables the feature; until then the Claude adapter may be shipped behind the unverified flag or use fallback layout B.
- **Codex CLI, Gemini CLI, GitHub Copilot**: not tested; their adapters return "disable unsupported" until verified.
- File watchers of Kilo reacting to the move: not observed (no long-running session was used).

## Decision

Layout A is adopted (D-Q1 a) with the per-assistant hook `getDisabledPath` so any assistant can switch to layout B (`.ai-swissknife/_disabled/<assistant>/<kind>/<name>`) without touching the engine. Kilo is cleared; the others stay disabled-by-default until verified.
