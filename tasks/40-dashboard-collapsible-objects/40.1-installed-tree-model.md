## Do

Create `src/engine/installedTree.ts` exporting `buildInstalledTree(managed, observed, opts?)` → `InstalledObject[]`:

- `InstalledObject { kind, name, identity, places: Place[], worstState }`.
- `Place { key /* getIdentityKey, unique per place */, assistant, scope, membership: 'managed' | 'unmanaged', state, match? /* observed: identical | different | none, sourceId */ }`. `state` is an explicit union covering managed (`checking`, `up-to-date`, `update-available`, `modified-locally`, `modified-and-update-available`, `missing-on-disk`) and unmanaged (`identical`, `different`, `local-only`); the drift status for managed places is injected later by the renderer, so accept an optional `statusByKey` map.
- Objects are keyed by `(kind, name)` using the same identity rule as `getArtifactIdentity`; managed and observed copies of the same object join the same parent. If `getArtifactIdentity` cannot be applied to an observed artifact, define one shared helper and use it for both (do not invent a second rule), documenting it in the file header.
- `worstState` by a single severity table exported next to the type (missing-on-disk > modified-and-update > modified-locally > update-available > different > local-only > checking > identical > up-to-date, adjust only if the existing `severities` map in `dashboard.ts:~1925-1935` says otherwise — reuse its ordering and note any difference).
- Places sorted by the `ALL_ADAPTERS` order (as at `dashboard.ts:620-624`), then scope (global before project).
