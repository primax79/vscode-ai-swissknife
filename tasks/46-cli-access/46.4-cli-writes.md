# 46.4 — Write commands behind `--write`

One task, one commit (if the services extraction makes it larger, report and propose a split). Depends on 46.1, 46.3. Working assumption MC-Q2 of the plan applies until the owner changes it.

**Read first:** `plan.md`, `src/engine/installMatrix.ts` (`applyInstallMatrix`), `src/engine/{apply,softDelete}.ts`, `src/ui/installedView.ts` (`removeManagedInstallation`, `doUninstallItem`: the logic to move into the engine), `src/ui/sourcesView.ts` (add/remove source manifest edits), the 44.1 validators, 46.3's lock.

## Do

1. **Gate**: write commands exist only when `--write` is passed; without it they fail with `WRITE_NOT_ENABLED` and a hint. Kinds `hook` and `mcp-server` are refused (`KIND_NOT_ALLOWED`) unless `--allow-code-kinds` is also passed.
2. **Extract the minimum into the engine** (no `vscode`): `uninstallInstallation(inst, {mode: 'soft'|'hard'})` (the state-record removal + `softDeletePath` already used by the UI) and `addSource` / `removeSource` manifest mutations (with the 44.1 validation and the duplicate-id rule: error `DUPLICATE_ID` unless `--replace`). The UI methods call the extracted functions; their behaviour and tests stay unchanged.
3. **Commands**: `apply-install --plan-from-args ...` (same arguments as `plan-install` plus `--overwrite`; re-plans internally and applies only new targets, and conflicts only with `--overwrite`; returns per-target outcomes), `uninstall <key> [--hard]` (soft by default), `source add <type> <location> [--id --name --scope]` (location validated, id/name derived with `deriveSourceDefaults` when omitted), `source remove <id> --scope`, `redistribute <path|item> [--scope ...] [--force] [--install-missing]` (v1: only items installed from a local `local-folder` source, plan-first; spec in `specs/dev-deploy-study.md`), and `update --all [--scope --assistant --source --kind] [--include-modified]` built on `planUpdateAll`/`applyUpdateAll` of initiative 47 (plan printed first; same skip-modified default).
4. Every write runs inside `withStateLock` (46.3) and returns the list of files it changed.

## Verification

Tests on temp fixtures: each command refused without `--write`; `hook`/`mcp-server` refused without the second flag; apply-install applies new targets and skips conflicts unless `--overwrite`; uninstall soft moves to `_deleted/` and `--hard` removes; add source rejects a bad URL / duplicate id (negative cases from 44.1); the UI's uninstall/add/remove tests still pass untouched (they now exercise the extracted engine). Two concurrent CLI writers do not lose updates. `npm test` green, `npm run build` clean.
