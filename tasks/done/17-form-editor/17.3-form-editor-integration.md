# 17.3 — Create/edit commands & integration

> Part of [Form editor webview](plan.md) · spec: [../specs/phase-4-spec.md](../../specs/phase-4-spec.md) §3

## Goal

Register the commands that open the form editor and wire them into the
existing Installed view and Dashboard, so the form editor is reachable from
the UI, not just callable in isolation.

This task must produce one commit containing only its changes.

## Steps

1. Register `aiSwissknife.createArtifact` (prompts for kind + target
   assistant + scope, opens `FormEditorPanel` with empty defaults) and
   `aiSwissknife.editArtifact` (opens `FormEditorPanel` pre-loaded for a
   given `ManagedInstallation`) in `src/extension.ts`.
2. Add an inline "Edit" action on items in `src/ui/installedView.ts` and a
   button/action in `src/ui/dashboard.ts`'s webview UI, both invoking
   `aiSwissknife.editArtifact` with the selected item.
3. Add an entry point for "create new" reachable from the Installed view's
   toolbar (parallel to how Sources/Available already expose their own
   creation entry points).

## Verification

- Run full test suite, lint, typecheck, build.
- Manually: create a new agent via the form editor, confirm it appears in
  Installed view with correct drift status (`up-to-date`, since it was just
  written); edit an existing item from both Installed view and Dashboard.
