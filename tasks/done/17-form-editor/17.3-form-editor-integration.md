# 17.3 — Comandi di creazione/modifica e integrazione

> Parte di [Webview dell'editor a modulo](plan.md) · spec: [../specs/phase-4-spec.md](../../specs/phase-4-spec.md) §3

## Goal

Registrare i comandi che aprono il form editor e collegarli alla
vista Installed e alla Dashboard esistenti, in modo che il form editor sia raggiungibile
dalla UI e non solo invocabile isolatamente.

Questo task deve produrre un singolo commit contenente solo le proprie modifiche.

## Steps

1. Registrare `aiSwissknife.createArtifact` (chiede tipo + assistente di destinazione
   + scope, apre `FormEditorPanel` con i valori predefiniti vuoti) e
   `aiSwissknife.editArtifact` (apre `FormEditorPanel` precaricato per una
   data `ManagedInstallation`) in `src/extension.ts`.
2. Aggiungere un'azione inline "Edit" sugli elementi in `src/ui/installedView.ts` e un
   pulsante/azione nella UI webview di `src/ui/dashboard.ts`, entrambi che invocano
   `aiSwissknife.editArtifact` con l'elemento selezionato.
3. Aggiungere un punto di ingresso per "crea nuovo" raggiungibile dalla barra degli strumenti
   della vista Installed (in parallelo a come Sources/Available espongono già i propri
   punti di ingresso di creazione).

## Verification

- Eseguire l'intera suite di test, lint, typecheck, build.
- Manualmente: creare un nuovo agent tramite il form editor, confermare che appaia nella
  vista Installed con lo stato di drift corretto (`up-to-date`, poiché è stato appena
  scritto); modificare un elemento esistente sia dalla vista Installed sia dalla Dashboard.
