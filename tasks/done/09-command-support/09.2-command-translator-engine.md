# 09.2 — Traduttore dei command e motore di installazione

> Parte di [Supporto agli artefatti command](plan.md) · specifica: [../specs/phase-2-spec.md](../../specs/phase-2-spec.md) · richiede 09.1

## Goal

Implementare `translateCommand`, `canonicalCommandHash` ed estendere `planInstall` / `applyInstall` per gestire `kind: 'command'`.

Questo task deve produrre un unico commit contenente solo le proprie modifiche.

## Steps

1. Creare `src/translator/command.ts`:
   - `translateCommand(source: CanonicalCommand, target: AssistantId): TranslationResult<CanonicalCommand>`
   - Tradurre i campi senza perdita per Claude e Kilo.
   - Restituire `overall: 'unsupported'` per gli assistenti non supportati.

2. In `src/adapters/codec.ts`:
   - Implementare `canonicalCommandHash(cmd: CanonicalCommand): string` (sha256 deterministico).

3. Estendere `src/engine/types.ts`:
   - Aggiungere `kind: 'command'` con `content: CanonicalCommand` a `PreparedInstall`.

4. Estendere `src/engine/plan.ts` e `src/engine/apply.ts`:
   - Supportare `artifact.kind === 'command'`.
   - Installazione atomica a file singolo con backup, verifica, rollback e tracciamento dello stato.

5. Aggiungere test in `src/translator/command.test.ts` e `src/engine/install.test.ts`.

## Verification

- Eseguire l'intera suite di test, lint, typecheck e build.
- Testare la traduzione dei command Claude -> Kilo e Kilo -> Claude.
- Testare l'installazione atomica di un command e la persistenza dello stato in `.ai-swissknife/state.json`.
