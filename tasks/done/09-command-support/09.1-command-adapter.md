# 09.1 — Modello CanonicalCommand e adapter command per Claude/Kilo

> Parte di [Supporto agli artefatti command](plan.md) · specifica: [../specs/phase-2-spec.md](../../specs/phase-2-spec.md)

## Goal

Aggiungere il modello canonico `CanonicalCommand` e implementare lettura, scrittura, parsing, serializzazione ed elenco dei file command in `ClaudeAdapter` e `KiloAdapter`.

Questo task deve produrre un unico commit contenente solo le proprie modifiche.

## Steps

1. Definire `CanonicalCommand` in `src/adapters/types.ts`:
```ts
export interface CanonicalCommand {
  name: string;
  description: string;
  agent?: string;
  model?: string;
  subtask?: boolean;
  body: string;
  extraFields: Record<string, unknown>;
}
```

2. Implementare il codec dei command Claude in `src/adapters/claude.ts`:
   - `commandPath(name: string, loc: LocationRef): string` -> `.claude/commands/<name>.md` (progetto) o `~/.claude/commands/<name>.md` (globale)
   - `parseClaudeCommandMarkdown(raw: string, defaultName?: string): CanonicalCommand`
   - `serializeClaudeCommandMarkdown(cmd: CanonicalCommand): string`
   - `readCommand`, `writeCommand`, `listCommands`.

3. Implementare il codec dei command Kilo in `src/adapters/kilo.ts`:
   - `commandPath(name: string, loc: LocationRef): string` -> `.kilo/command/<name>.md` (progetto) o `~/.config/kilo/command/<name>.md` (globale)
   - Supportare sia `.kilo/command/` sia `.kilo/commands/` in lettura.
   - `parseKiloCommandMarkdown(raw: string, defaultName?: string): CanonicalCommand`
   - `serializeKiloCommandMarkdown(cmd: CanonicalCommand): string` — **Schema rigoroso**: emettere nel frontmatter esclusivamente `description`, `agent`, `model`, `subtask` (non emettere mai `name:` o chiavi non riconosciute nel frontmatter).
   - `readCommand`, `writeCommand`, `listCommands`.

4. Aggiungere unit test in `src/adapters/claude.test.ts` e `src/adapters/kilo.test.ts`.

## Verification

- Eseguire l'intera suite di test, lint, typecheck e build.
- Testare la serializzazione e la lettura round-trip dei file command in Claude e Kilo.
- Dimostrare che il frontmatter dei command Kilo non contiene mai chiavi non valide che innescano errori del parser.
