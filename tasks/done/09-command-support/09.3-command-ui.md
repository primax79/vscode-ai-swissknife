# 09.3 — Discovery dei command e integrazione nella UI

> Parte di [Supporto agli artefatti command](plan.md) · specifica: [../specs/phase-2-spec.md](../../specs/phase-2-spec.md) · richiede 09.2

## Goal

Rilevare i file markdown dei command nei resolver `localFolder` e `gitCustom`, visualizzarli nelle viste ad albero Available e Installed con l'icona del terminale (`terminal`) e abilitare l'installazione singola e in batch.

Questo task deve produrre un unico commit contenente solo le proprie modifiche.

## Steps

1. In `src/sources/detect.ts`:
   - Aggiungere `findCommandFiles(rootDir: string): Promise<{ commands: DetectedCommandFile[]; diagnostics: DetectionDiagnostic[]; }>`.
   - Scansionare `*.command.md` o i file all'interno delle directory `commands/` / `command/` (escludendo `README.md`).

2. In `src/sources/localFolder.ts` e `src/sources/gitCustom.ts`:
   - Mappare i command rilevati in `Package` con `Artifact (kind: 'command')`.
   - Implementare `resolveArtifactContent` per `artifact.kind === 'command'`.

3. In `src/ui/availableView.ts` e `src/ui/installedView.ts`:
   - Renderizzare i command con `new vscode.ThemeIcon('terminal')`.
   - Visualizzare il tipo `command` nelle descrizioni e nei tooltip.

4. Aggiungere unit test e fixture.

## Verification

- Eseguire l'intera suite di test, lint, typecheck e build.
- Verificare discovery, anteprima e installazione dei command da sorgenti locali e Git.
