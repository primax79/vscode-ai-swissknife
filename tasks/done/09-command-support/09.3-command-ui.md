# 09.3 — Command discovery & UI integration

> Part of [Command artifact support](plan.md) · spec: [../specs/phase-2-spec.md](../../specs/phase-2-spec.md) · requires 09.2

## Goal

Detect command markdown files in `localFolder` and `gitCustom` resolvers, display them in Available and Installed tree views with terminal icon (`terminal`), and enable single and batch installation.

This task must produce one commit containing only its changes.

## Steps

1. In `src/sources/detect.ts`:
   - Add `findCommandFiles(rootDir: string): Promise<{ commands: DetectedCommandFile[]; diagnostics: DetectionDiagnostic[]; }>`.
   - Scan for `*.command.md` or files inside `commands/` / `command/` directories (excluding `README.md`).

2. In `src/sources/localFolder.ts` and `src/sources/gitCustom.ts`:
   - Map detected commands to `Package` with `Artifact (kind: 'command')`.
   - Implement `resolveArtifactContent` for `artifact.kind === 'command'`.

3. In `src/ui/availableView.ts` and `src/ui/installedView.ts`:
   - Render commands with `new vscode.ThemeIcon('terminal')`.
   - Display kind: `command` in descriptions and tooltips.

4. Add unit tests and fixtures.

## Verification

- Run full test suite, lint, typecheck, build.
- Verify discovery, preview, and install of commands from local and Git sources.
