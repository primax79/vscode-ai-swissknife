# 08.2 — Traduttore degli agent e motore di installazione

> Parte di [Supporto agli artefatti agent](plan.md) · specifica: [../specs/phase-2-spec.md](../../specs/phase-2-spec.md) · richiede 08.1

## Goal

Implementare `translateAgent` traducendo tra l'array `tools` di Claude e il blocco `mode` + `permission` di Kilo, ed estendere `planInstall` / `applyInstall` per gestire `kind: 'agent'`.

Questo task deve produrre un unico commit contenente solo le proprie modifiche.

## Steps

1. Creare `src/translator/agent.ts`:
   - `translateAgent(source: CanonicalAgent, target: AssistantId): TranslationResult<CanonicalAgent>`
   - Mappare l'array `tools` nel blocco `permission` di Kilo (`read`, `edit`, `bash`, `skill`, `webfetch`, `mcp`).
   - Mappare il blocco `permission` di Kilo nell'array `tools` di Claude.
   - Preservare il markdown `body` ed `extraFields`.
   - Emettere una `TranslationDiagnostic` per i tool personalizzati non mappati.

2. Estendere `src/engine/plan.ts`:
   - Supportare `artifact.kind === 'agent'`.
   - Risolvere il contenuto dell'agent dalla sorgente tramite `resolveArtifactContent`.
   - Calcolare il file dell'agent proposto (singolo file markdown con hash del contenuto).
   - Ispezionare il file dell'agent di destinazione su disco per il rilevamento dei conflitti.

3. Estendere `src/engine/apply.ts`:
   - Gestire lo scambio atomico a file singolo per gli agent (scrivere il file di staging -> scambiare -> verificare -> aggiornare `state.json`).

4. Aggiungere unit test in `src/translator/agent.test.ts` e `src/engine/install.test.ts`.

## Verification

- Eseguire l'intera suite di test, lint, typecheck e build.
- Testare la traduzione degli agent Claude -> Kilo e Kilo -> Claude.
- Testare l'installazione atomica di un agent e la persistenza dello stato.
