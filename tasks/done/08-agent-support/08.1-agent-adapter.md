# 08.1 — Modello CanonicalAgent e adapter agent per Claude/Kilo

> Parte di [Supporto agli artefatti agent](plan.md) · specifica: [../specs/phase-2-spec.md](../../specs/phase-2-spec.md)

## Goal

Aggiungere il modello canonico `CanonicalAgent` e implementare lettura, scrittura, parsing, serializzazione ed elenco dei file agent in `ClaudeAdapter` e `KiloAdapter`.

Questo task deve produrre un unico commit contenente solo le proprie modifiche.

## Steps

1. Definire `CanonicalAgent` in `src/adapters/types.ts`:
```ts
export interface CanonicalAgent {
  name: string;
  description: string;
  mode?: 'primary' | 'subagent' | 'all';
  tools: string[];
  permissions: Record<string, 'allow' | 'deny' | 'ask'>;
  model?: string;
  variant?: string;
  body: string;
  extraFields: Record<string, unknown>;
}
```

2. Implementare il codec degli agent Claude in `src/adapters/claude.ts`:
   - `parseAgentMarkdown(raw: string): Omit<CanonicalAgent, 'permissions'>`
   - `serializeAgentMarkdown(agent: CanonicalAgent): string`
   - `agentPath(name: string, loc: { scope: Scope; projectRoot?: string }): string` -> `<loc>/.claude/agents/<name>.md` (progetto) o `~/.claude/agents/<name>.md` (globale)
   - `readAgent(name: string, loc: { scope: Scope; projectRoot?: string }): Promise<CanonicalAgent | null>`
   - `writeAgent(agent: CanonicalAgent, loc: { scope: Scope; projectRoot?: string }): Promise<void>`
   - `listAgents(loc: { scope: Scope; projectRoot?: string }): Promise<string[]>`

3. Implementare il codec degli agent Kilo in `src/adapters/kilo.ts`:
   - Supportare sia `.kilo/agents/<name>.md` sia `.kilo/agent/<name>.md` in lettura; scrivere in `.kilo/agents/<name>.md` (progetto) o `~/.config/kilo/agents/<name>.md` (globale).
   - `parseAgentMarkdown(raw: string): CanonicalAgent` (legge `mode`, il blocco `permission:`, `model`, `variant`).
   - `serializeAgentMarkdown(agent: CanonicalAgent): string` (formatta un frontmatter YAML pulito con stringhe su singola riga sottoposte a escape).
   - `readAgent`, `writeAgent`, `listAgents`.

4. Aggiungere unit test completi in `src/adapters/claude.test.ts` e `src/adapters/kilo.test.ts`.

## Verification

- Eseguire l'intera suite di test, lint, typecheck e build.
- Testare la serializzazione e la lettura round-trip di fixture di agent reali da Claude e Kilo.
- Testare la preservazione dei permessi e dell'array dei tool.
