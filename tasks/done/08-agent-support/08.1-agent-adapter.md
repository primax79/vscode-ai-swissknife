# 08.1 — CanonicalAgent model and Claude/Kilo agent adapters

> Part of [Agent artifact support](plan.md) · spec: [../specs/phase-2-spec.md](../../specs/phase-2-spec.md)

## Goal

Add the canonical `CanonicalAgent` model and implement agent file reading, writing, parsing, serialization, and listing in `ClaudeAdapter` and `KiloAdapter`.

This task must produce one commit containing only its changes.

## Steps

1. Define `CanonicalAgent` in `src/adapters/types.ts`:
```ts
export interface CanonicalAgent {
  name: string;
  description: string;
  mode?: 'primary' | 'subagent' | 'all';
  tools: string[];
  permissions: Record<string, 'allow' | 'deny' | 'ask'>;
  model?: string;
  variant?: string;
  body: string;
  extraFields: Record<string, unknown>;
}
```

2. Implement Claude agent codec in `src/adapters/claude.ts`:
   - `parseAgentMarkdown(raw: string): Omit<CanonicalAgent, 'permissions'>`
   - `serializeAgentMarkdown(agent: CanonicalAgent): string`
   - `agentPath(name: string, loc: { scope: Scope; projectRoot?: string }): string` -> `<loc>/.claude/agents/<name>.md` (project) or `~/.claude/agents/<name>.md` (global)
   - `readAgent(name: string, loc: { scope: Scope; projectRoot?: string }): Promise<CanonicalAgent | null>`
   - `writeAgent(agent: CanonicalAgent, loc: { scope: Scope; projectRoot?: string }): Promise<void>`
   - `listAgents(loc: { scope: Scope; projectRoot?: string }): Promise<string[]>`

3. Implement Kilo agent codec in `src/adapters/kilo.ts`:
   - Support both `.kilo/agents/<name>.md` and `.kilo/agent/<name>.md` on read; write to `.kilo/agents/<name>.md` (project) or `~/.config/kilo/agents/<name>.md` (global).
   - `parseAgentMarkdown(raw: string): CanonicalAgent` (reads `mode`, `permission:` block, `model`, `variant`).
   - `serializeAgentMarkdown(agent: CanonicalAgent): string` (formats clean YAML frontmatter with single-line escaped strings).
   - `readAgent`, `writeAgent`, `listAgents`.

4. Add comprehensive unit tests in `src/adapters/claude.test.ts` and `src/adapters/kilo.test.ts`.

## Verification

- Run full test suite, lint, typecheck, build.
- Test round-trip serialization and reading of real agent fixtures from Claude and Kilo.
- Test permission and tool array preservation.
