# 08.3 — Agent detection & UI integration

> Part of [Agent artifact support](plan.md) · spec: [../specs/phase-2-spec.md](../../specs/phase-2-spec.md) · requires 08.2

## Goal

Detect agent markdown files in `localFolder` and `gitCustom` resolvers, display them in Available and Installed tree views with robot icon (`symbol-misc` / `robot`), and enable single and batch installation.

This task must produce one commit containing only its changes.

## Steps

1. In `src/sources/detect.ts`:
   - Add `findAgentFiles(baseDir: string): Promise<DetectedAgentFile[]>` scanning for `*.agent.md` or `.claude/agents/*.md` or `.kilo/agents/*.md`.
   - Forward agent diagnostics if frontmatter is invalid.

2. In `src/sources/localFolder.ts` and `src/sources/gitCustom.ts`:
   - Return packages with both `skill` and `agent` artifacts.
   - Implement `resolveArtifactContent` for `artifact.kind === 'agent'`.

3. In `src/ui/availableView.ts` and `src/ui/installedView.ts`:
   - Render agents with `iconPath = new vscode.ThemeIcon('robot')` or `person`.
   - Update descriptions and tooltips showing kind: `agent`.

4. Add unit tests and fixtures.

## Verification

- Run full test suite, lint, typecheck, build.
- Verify discovery, preview, and install of agents from local and Git sources.
