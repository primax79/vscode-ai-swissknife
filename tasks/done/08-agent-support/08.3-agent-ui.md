# 08.3 — Rilevamento degli agent e integrazione nella UI

> Parte di [Supporto agli artefatti agent](plan.md) · specifica: [../specs/phase-2-spec.md](../../specs/phase-2-spec.md) · richiede 08.2

## Goal

Rilevare i file markdown degli agent nei resolver `localFolder` e `gitCustom`, visualizzarli nelle viste ad albero Available e Installed con l'icona robot (`symbol-misc` / `robot`) e abilitare l'installazione singola e in batch.

Questo task deve produrre un unico commit contenente solo le proprie modifiche.

## Steps

1. In `src/sources/detect.ts`:
   - Aggiungere `findAgentFiles(baseDir: string): Promise<DetectedAgentFile[]>` scansionando `*.agent.md` oppure `.claude/agents/*.md` oppure `.kilo/agents/*.md`.
   - Inoltrare le diagnostiche dell'agent se il frontmatter non è valido.

2. In `src/sources/localFolder.ts` e `src/sources/gitCustom.ts`:
   - Restituire pacchetti con artefatti sia `skill` sia `agent`.
   - Implementare `resolveArtifactContent` per `artifact.kind === 'agent'`.

3. In `src/ui/availableView.ts` e `src/ui/installedView.ts`:
   - Renderizzare gli agent con `iconPath = new vscode.ThemeIcon('robot')` oppure `person`.
   - Aggiornare descrizioni e tooltip mostrando il tipo: `agent`.

4. Aggiungere unit test e fixture.

## Verification

- Eseguire l'intera suite di test, lint, typecheck e build.
- Verificare discovery, anteprima e installazione degli agent da sorgenti locali e Git.
