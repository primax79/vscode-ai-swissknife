# 14.2 — Motore di promozione

> Parte di [Rilevamento e promozione](plan.md) · spec: [../specs/phase-3-spec.md](../../specs/phase-3-spec.md) · richiede 14.1

## Goal

Implementare `promoteObservedArtifact` in `src/engine/discovery.ts` che calcola l'hash corrente del contenuto su disco per un `ObservedArtifact` e lo registra come `ManagedInstallation` in `state.json`.

Questo task deve produrre un singolo commit contenente solo le proprie modifiche.

## Steps

1. In `src/engine/discovery.ts`:
   - Implementare `promoteObservedArtifact(observed: ObservedArtifact, sourceId?: string, homeRoot?: string): Promise<ManagedInstallation>`.
   - Legge l'artefatto su disco tramite l'adapter appropriato.
   - Calcola l'hash canonico (`canonicalSkillHash`, `canonicalAgentHash`, `canonicalCommandHash`, `canonicalMcpServerHash`).
   - Aggiunge `ManagedInstallation` a `state.json` tramite `readState` / `writeState`.
   - Restituisce il `ManagedInstallation` creato.

2. Aggiungere unit test in `src/engine/discovery.test.ts`.

## Verification

- Eseguire l'intera suite di test, lint, typecheck, build.
- Testare la promozione di skill, agent, command e server MCP osservati allo stato gestito.
