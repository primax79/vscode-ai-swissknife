# 14.3 — UI integration for discovery & promotion

> Part of [Discovery & promotion](plan.md) · spec: [../specs/phase-3-spec.md](../../specs/phase-3-spec.md) · requires 14.2

## Goal

Render unmanaged `ObservedArtifact`s under an "Unmanaged Items" section in the Installed view, and provide `AI Swissknife: Promote to Managed` command and inline button (`shield`).

This task must produce one commit containing only its changes.

## Steps

1. In `src/ui/installedView.ts`:
   - Display `Unmanaged (Assistant Scope)` group items.
   - Display `ObservedArtifactItem` with `eye` / `unverified` icon.
   - Implement `promoteItem(item: ObservedArtifactItem)`: calls `promoteObservedArtifact`, refreshes tree view, and reports success.

2. In `package.json`:
   - Register command `aiSwissknife.promoteItem` ("Promote to Managed", icon: `"$(shield)"`).
   - Add inline action on `observedArtifactItem`.

3. Add unit tests in `src/ui/ui.test.ts`.

## Verification

- Run full test suite, lint, typecheck, build.
- Test discovery and promotion directly in the tree view.
