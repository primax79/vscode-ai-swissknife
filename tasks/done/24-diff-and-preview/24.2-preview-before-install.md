# 24.2 — Azione di anteprima prima dell'installazione

> Parte di [Diff rispetto all'originale + anteprima prima dell'installazione](plan.md) · spec: [../specs/phase-6-spec.md](../../specs/phase-6-spec.md) §4.2

## Goal

Consentire all'utente di vedere cosa verrà effettivamente installato prima di confermare, riutilizzando
il contenuto già risolto da `planInstall` — a costo zero, senza alcuna nuova risoluzione.
Indipendente dall'iniziativa 23 e da 24.1 — può essere avviato immediatamente.

Questo task deve produrre un singolo commit contenente solo le proprie modifiche.

## Steps

1. In `AvailableTreeDataProvider.installArtifact` e `installBatch`
   (`src/ui/availableView.ts:476-729`), dopo che `planInstall` restituisce
   `prepared` e prima della finestra di dialogo di conferma esistente `showInformationMessage`,
   aggiungere un'azione `Preview` accanto alle scelte esistenti `Install`/
   `Overwrite`.
2. `Preview` apre `prepared.content` in sola lettura (un documento virtuale tramite un
   `TextDocumentContentProvider`, seguendo lo stesso pattern con schema personalizzato di 24.1 se
   quel task è già stato completato — altrimenti introdurlo qui affinché 24.1 lo riutilizzi).
   Per `skill`, mostrare specificamente il contenuto del file principale `SKILL.md`, senza
   tentare di visualizzare un'intera cartella; `prepared.plan.proposedFiles` elenca
   gli altri file per percorso come riferimento.
3. Dopo l'anteprima, l'utente deve comunque vedere la finestra di dialogo di conferma originale
   (`Install`/`Overwrite`) — `Preview` non installa nulla di per sé, si limita a
   leggere.
4. Applicare la stessa aggiunta di `Preview` al flusso di conferma di `installBatch`,
   limitandola all'anteprima di un elemento alla volta del batch (es. un
   `QuickPick` secondario per scegliere quale elemento visualizzare in anteprima), non a una vista
   combinata dell'intero batch.

## Verification

- Verifica manuale: avviare l'installazione su un elemento Available, scegliere
  `Preview`, confermare che il contenuto risolto/tradotto venga visualizzato correttamente,
  e confermare che scegliere `Install` subito dopo esegua comunque l'installazione correttamente (ossia
  che `Preview` non abbia effetti collaterali sull'installazione successiva).
- Eseguire l'intera suite di test, lint, typecheck, build.
