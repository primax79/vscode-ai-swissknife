## Cosa fare

Creare `src/sources/sourceDefaults.ts` (senza import di `vscode`) che esporta:

- `validateLocation(type: SourceType, value: string): string | null` — messaggio di errore oppure null. Tipi git: HTTPS `https://host/...` o SSH (`git@host:org/repo(.git)`/`ssh://`); `remote-url`: URL `http(s)://`; `local-folder`: non vuoto, non un URL.
- `deriveSourceDefaults(type, location): { id: string; name: string }` — id = slug in minuscolo dell'ultimo segmento del percorso (nome del repository senza `.git`, nome base della cartella, nome del file dell'URL senza estensione), `[a-z0-9-]`, mai vuoto (fallback `source`); name = id reso leggibile (`team-skills` → `Team skills`).
