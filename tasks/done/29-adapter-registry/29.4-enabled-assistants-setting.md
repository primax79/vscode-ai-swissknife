# 29.4 — Impostazione VS Code per gli assistenti abilitati

> Parte di [Registro degli adapter e configurazione](plan.md) · spec: [../specs/adapter-and-source-registries.md](../../specs/adapter-and-source-registries.md) §4.5, §3 (Decisioni vincolate), §2 (Non-obiettivi)

## Goal

Un'impostazione nativa di VS Code che controlla quali sezioni della sidebar degli assistenti
sono visibili, più la registrazione di provider/viste guidata dal registro in
`extension.ts` a cui si riferisce effettivamente la richiesta "foreach, non una serie di if" della nota
a livello di cablaggio.

Questo task deve produrre un singolo commit contenente esclusivamente le proprie modifiche.

## Steps

1. Aggiungere in `package.json` sotto `contributes` (questa estensione **non** dichiara
   alcuna `configuration` oggi — confermarlo con `grep -n '"configuration"'
   package.json` prima di iniziare, in modo da posizionarla come nuova chiave di primo livello
   sotto `contributes`, senza fonderla in qualcos'altro):
   ```json
   "configuration": {
     "title": "AI Swissknife",
     "properties": {
       "aiSwissknife.enabledAssistants": {
         "type": "array",
         "items": {
           "type": "string",
           "enum": ["claude-code", "kilo-code", "github-copilot", "codex-cli", "gemini-cli"]
         },
         "default": ["claude-code", "kilo-code", "github-copilot", "codex-cli", "gemini-cli"],
         "description": "Which AI assistants show their own sidebar section and appear in assistant pickers."
       }
     }
   }
   ```
2. In `src/adapters/registry.ts` (29.2), aggiungere
   `getEnabledAdapters(): Adapter[]` — legge
   `vscode.workspace.getConfiguration('aiSwissknife').get<AssistantId[]>('enabledAssistants', ALL_ADAPTERS.map(a => a.assistant))`
   (l'argomento predefinito esplicito è importante: un'impostazione vuota/mancante deve
   ripiegare su "tutti abilitati", in linea con il valore predefinito di `package.json`, non
   su "nessuno") e filtra `ALL_ADAPTERS` ai soli id presenti.
3. In `src/extension.ts`, dentro `activate()`: sostituire le cinque righe scritte a mano
   `const claudeProvider = new AssistantTreeDataProvider(installedProvider,
   'claude-code'); const kiloProvider = ...` (riconfermare prima la struttura
   attuale — questo file è già stato modificato in 29.3) con un unico ciclo su
   `ALL_ADAPTERS` che costruisce una `Map<AssistantId, AssistantTreeDataProvider>`
   (o equivalente), e registrare una chiamata `vscode.window.registerTreeDataProvider`
   per ciascuna voce tramite quello stesso ciclo invece di cinque chiamate separate.
4. Aggiungere un piccolo helper `syncEnabledAssistantContextKeys()` (in
   `extension.ts`, o in un nuovo piccolo `src/ui/enabledAssistants.ts` se supera
   poche righe) che, per ogni adapter in `ALL_ADAPTERS`, invoca
   `vscode.commands.executeCommand('setContext', \`aiSwissknife.enabled.${adapter.assistant}\`,
   enabledIds.includes(adapter.assistant))`. Invocarlo una volta durante
   `activate()` (dopo aver calcolato `getEnabledAdapters()`) e di nuovo all'interno di un
   listener `vscode.workspace.onDidChangeConfiguration(e => { if
   (e.affectsConfiguration('aiSwissknife.enabledAssistants')) { ... } })`
   registrato in `context.subscriptions`.
5. Per ciascuna delle cinque voci `contributes.views` sotto
   `aiSwissknife.installed.<assistant-id>` in `package.json`, aggiungere
   `"when": "aiSwissknife.enabled.<assistant-id>"` (ad es.
   `"when": "aiSwissknife.enabled.claude-code"` sulla voce di Claude Code).
   Non aggiungere una clausola `when` alla vista `aiSwissknife.sources` — quella non è
   specifica di un assistente.

## Verification

- Eseguire l'intera suite di test, typecheck, lint e build.
- Unit test (estendere la copertura di test esistente di `src/extension.ts` in
  `src/ui/ui.test.ts` se è lì che `activate()` viene già esercitato —
  confermarlo prima cercando `extension.activate` con grep in quel file):
  `getEnabledAdapters()` senza alcuna impostazione configurata restituisce tutti e 5; con
  il mock `vscode.workspace.getConfiguration` che restituisce
  `['claude-code']`, restituisce esattamente quel singolo adapter (verificato per identità
  rispetto a `claudeAdapter`, non solo tramite stringa id).
- Manualmente nell'Extension Development Host: aprire le Impostazioni, cercare
  "AI Swissknife", confermare che l'impostazione array a selezione multipla appaia con la
  descrizione corretta e tutti i 5 valori enum; deselezionare un assistente, confermare che
  la relativa sezione nella sidebar scompaia **senza ricaricare la finestra** (il
  listener `onDidChangeConfiguration` è ciò che viene verificato qui);
  riselezionarlo e confermare che la sezione riappaia.
