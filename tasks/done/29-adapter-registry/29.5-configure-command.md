# 29.5 — Comando "Configure enabled assistants"

> Parte di [Registro degli adapter e configurazione](plan.md) · spec: [../specs/adapter-and-source-registries.md](../../specs/adapter-and-source-registries.md) §4.5

## Goal

Un punto di accesso facilmente individuabile nel riquadro comandi per l'impostazione di 29.4 — la
richiesta letterale di un "menu di configurazione" nella nota — così che l'utente non debba conoscere
l'id esatto dell'impostazione per trovarla nella UI delle Impostazioni.

Questo task deve produrre un singolo commit contenente esclusivamente le proprie modifiche.

## Steps

1. Aggiungere `aiSwissknife.configureEnabledAssistants` in `package.json` sotto `contributes.commands`
   (titolo ad es. "Configure Enabled Assistants...",
   icona `$(gear)` o simile — scegliere qualcosa che non sia già usato da un altro
   comando nella stessa lista, controllando prima con `grep -n '"icon"' package.json`),
   con `category: "AI Swissknife"` come ogni altro comando in quella lista.
2. Registrarlo in `src/extension.ts` accanto alle altre registrazioni di comandi,
   invocando un nuovo gestore (co-locato in
   `src/adapters/registry.ts` o in una piccola funzione dedicata — seguire
   il pattern già adottato da questo file per i suoi gestori più semplici,
   ad es. la struttura del gestore di `addSource`).
3. Gestore: leggere l'insieme attualmente abilitato tramite `getEnabledAdapters()`
   (29.4), mostrare
   `vscode.window.showQuickPick(ALL_ADAPTERS.map(a => ({ label: a.displayName, picked: enabledIds.includes(a.assistant) })), { canPickMany: true, placeHolder: 'Select which assistants to enable' })`,
   e se l'utente non ha annullato l'operazione, salvare gli id risultanti tramite
   `vscode.workspace.getConfiguration('aiSwissknife').update('enabledAssistants', selectedIds, vscode.ConfigurationTarget.Global)`.
   Non scrivere nulla se il QuickPick restituisce `undefined` (l'utente
   ha premuto Esc) — la stessa convenzione "no-op alla chiusura" già seguita da ogni altro
   comando in questa codebase (decisione di hardening "zero
   mutazioni su ogni percorso UI annullato" in `tasks/CONTEXT.md`).
4. Usare `ConfigurationTarget.Global` (scope utente), non `Workspace` — in linea con i
   Non-obiettivi della specifica (nessun override per progetto in questo passaggio).

## Verification

- Eseguire l'intera suite di test, typecheck, lint e build.
- Unit test: fare il mock di `showQuickPick` affinché restituisca uno specifico sottoinsieme, invocare il
  gestore del comando, verificare che `workspace.getConfiguration().update` sia stato chiamato
  esattamente con quel sottoinsieme e `ConfigurationTarget.Global`; fare il mock di
  `showQuickPick` affinché restituisca `undefined`, verificare che `update` **non** sia stato
  chiamato.
- Manualmente nell'Extension Development Host: eseguire "AI Swissknife: Configure
  Enabled Assistants..." dal riquadro comandi, confermare che il selettore
  pre-selezioni gli assistenti attualmente abilitati usando i loro veri nomi
  visualizzati (non gli id grezzi), commutare una selezione e confermare che la corrispondente
  sezione della sidebar compaia/scompaia esattamente come quando viene modificata
  direttamente dalle Impostazioni (verifica manuale di 29.4).
