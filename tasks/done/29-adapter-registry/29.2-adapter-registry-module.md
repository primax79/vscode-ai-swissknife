# 29.2 — `src/adapters/registry.ts`

> Parte di [Registro degli adapter e configurazione](plan.md) · spec: [../specs/adapter-and-source-registries.md](../../specs/adapter-and-source-registries.md) §4.2

## Goal

Un nuovo modulo che costituisce l'unica fonte di verità per "tutti gli adapter
noti" e "cercane uno per id" — l'elemento che permette a ogni task successivo di
eliminare un array letterale duplicato o una catena di `if` invece di mantenerne a mano
un'ulteriore copia.

Questo task deve produrre un singolo commit contenente esclusivamente le proprie modifiche. **Non** deve
ancora toccare alcuno dei punti di chiamata duplicati elencati nella specifica §0/§5
— quello è il task 29.3. Questo task aggiunge soltanto il nuovo modulo e i relativi unit
test.

## Steps

1. Creare `src/adapters/registry.ts` che esporti:
   - `ALL_ADAPTERS: readonly Adapter[]` — un array letterale dei cinque
     singleton esistenti (`claudeAdapter`, `kiloAdapter`, `copilotAdapter`,
     `codexAdapter`, `geminiAdapter`), importati dai rispettivi moduli reali
     (`../adapters/claude`, `./kilo`, `./copilot`, `./codex`, `./gemini` —
     verificare prima i nomi esatti di esportazione dei singleton tramite
     `grep -n "^export const" src/adapters/*.ts`, senza dare nulla per scontato).
   - `getAdapter(id: AssistantId): Adapter` — trova la voce corrispondente in
     `ALL_ADAPTERS`, solleva `` `Unsupported assistant: ${id}` `` se non ne trova nessuna
     (corrisponde al messaggio di errore esistente che le quattro funzioni `getAdapter` duplicate
     sollevano già, così nessun messaggio visibile ai chiamanti cambia quando
     29.3 li migrerà).
   - `getAdapterWithHomeRoot(id: AssistantId, homeRoot: string): Adapter`
     — sostituisce il ramo "costruisci una nuova istanza con una home
     root sovrascritta" delle quattro funzioni duplicate
     (`src/engine/discovery.ts:41-55`, `drift.ts:33-46`, `sync.ts:36-49`,
     `src/ui/formEditor.ts`). **Prima di scriverlo**, aprire tutti e quattro i file e
     confermare che il costruttore di ciascuna classe adapter accetti realmente
     `(homeRootFn: () => string)` in modo identico — la bozza del §4.2 della specifica
     presuppone che ciò valga ma lo segnala come non verificato; se il costruttore di una classe
     differisce, usare la costruzione effettivamente richiesta da ciascuna classe reale
     (ad es. un piccolo `switch`/tabella di lookup per assistente
     all'interno di questa singola funzione va bene — l'obiettivo è un'unica implementazione di
     questa mappatura, non zero diramazioni ovunque).
2. Non modificare `src/adapters/types.ts` né alcuno dei cinque file delle classi adapter
   in questo task (quello era 29.1, già completato).
3. Aggiungere `src/adapters/registry.test.ts` (co-locato, in linea con la
   convenzione esistente `*.test.ts` di questo progetto, ad es.
   `src/adapters/claude.test.ts`):
   - `ALL_ADAPTERS.length === 5` e contiene esattamente i cinque id `assistant`
     attesi, senza duplicati.
   - `getAdapter('claude-code') === claudeAdapter` (identità, non solo
     uguaglianza — conferma che restituisce il vero singleton e non una nuova
     istanza) per almeno due dei cinque id.
   - `getAdapter('bogus' as AssistantId)` solleva un'eccezione con un messaggio contenente
     `Unsupported assistant`.
   - `getAdapterWithHomeRoot('kilo-code', '/some/fake/home')` restituisce un
     adapter il cui `assistant === 'kilo-code'` e che **non** è lo
     stesso oggetto di `kiloAdapter` (conferma che ha costruito una nuova istanza
     legata alla home-root invece di restituire il singleton).

## Verification

- Eseguire l'intera suite di test, typecheck, lint e build — il nuovo `registry.test.ts`
  deve passare insieme alla suite esistente (238+ test al 2026-09-08;
  riverificare il conteggio attuale effettivo tramite la riga di riepilogo di `npm test`
  piuttosto che fidarsi di questo numero).
- `grep -rn "src/adapters/registry" src --include="*.ts"` deve mostrare solo
  i nuovi file propri di questo task che lo importano/esportano — nessun altro file
  vi fa ancora riferimento (quello è 29.3).
