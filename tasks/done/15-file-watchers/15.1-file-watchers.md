# 15.1 — File system watcher con refresh sottoposto a debounce

> Parte di [File watcher per la coerenza](plan.md) · spec: [../specs/phase-3-spec.md](../../specs/phase-3-spec.md)

## Goal

Implementare `setupFileWatchers` in `src/ui/watchers.ts` che monitora le cartelle di configurazione degli assistenti e avvia aggiornamenti UI con debounce.

Questo task deve produrre un singolo commit contenente solo le proprie modifiche.

## Steps

1. Creare `src/ui/watchers.ts`:
   - Pattern:
     - `**/.claude/**`
     - `**/.kilo/**`
     - `**/.github/{skills,agents,prompts}/**`
     - `**/.vscode/mcp.json`
     - `**/.ai-swissknife/**`
   - Helper di debounce (250ms).
   - Restituisce `vscode.Disposable[]`.

2. Aggiungere unit test in `src/ui/ui.test.ts`.

## Verification

- Eseguire l'intera suite di test, lint, typecheck, build.
- Testare l'attivazione delle callback del watcher e il debounce.
