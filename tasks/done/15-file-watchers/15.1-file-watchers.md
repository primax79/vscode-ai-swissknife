# 15.1 — File system watchers with debounced refresh

> Part of [File watchers for consistency](plan.md) · spec: [../specs/phase-3-spec.md](../../specs/phase-3-spec.md)

## Goal

Implement `setupFileWatchers` in `src/ui/watchers.ts` that watches assistant configuration folders and triggers debounced UI updates.

This task must produce one commit containing only its changes.

## Steps

1. Create `src/ui/watchers.ts`:
   - Patterns:
     - `**/.claude/**`
     - `**/.kilo/**`
     - `**/.github/{skills,agents,prompts}/**`
     - `**/.vscode/mcp.json`
     - `**/.ai-swissknife/**`
   - Debounce helper (250ms).
   - Returns `vscode.Disposable[]`.

2. Add unit tests in `src/ui/ui.test.ts`.

## Verification

- Run full test suite, lint, typecheck, build.
- Test watcher callback triggering and debouncing.
