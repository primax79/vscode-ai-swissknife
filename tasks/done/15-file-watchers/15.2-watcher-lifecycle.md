# 15.2 — Integrazione nel ciclo di vita dell'estensione

> Parte di [File watcher per la coerenza](plan.md) · spec: [../specs/phase-3-spec.md](../../specs/phase-3-spec.md) · richiede 15.1

## Goal

Integrare i file watcher in `src/extension.ts` affinché le viste `Sources` e `Installed` reagiscano automaticamente quando i file vengono creati, aggiornati o rimossi esternamente.

Questo task deve produrre un singolo commit contenente solo le proprie modifiche.

## Steps

1. In `src/extension.ts`:
   - Chiamare `setupFileWatchers` passando le callback di refresh.
   - Aggiungere i disposable restituiti a `context.subscriptions`.

2. Verificare build e pacchettizzazione.

## Verification

- Eseguire l'intera suite di test, lint, typecheck, build.
