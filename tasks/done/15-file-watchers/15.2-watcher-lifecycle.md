# 15.2 — Extension lifecycle wiring

> Part of [File watchers for consistency](plan.md) · spec: [../specs/phase-3-spec.md](../../specs/phase-3-spec.md) · requires 15.1

## Goal

Wire file watchers into `src/extension.ts` so `Sources` and `Installed` views react automatically when files are created, updated, or removed externally.

This task must produce one commit containing only its changes.

## Steps

1. In `src/extension.ts`:
   - Call `setupFileWatchers` passing refresh callbacks.
   - Push returned disposables to `context.subscriptions`.

2. Verify build and packaging.

## Verification

- Run full test suite, lint, typecheck, build.
