# 20.3 — Collegamento nella vista Sources e verifica

> Parte di [Sorgenti `remote-url` e `git-single-item`](plan.md) · spec: [../specs/phase-4-spec.md](../../specs/phase-4-spec.md) §6

## Goal

Collegare entrambi i nuovi resolver nel flusso "Add Source" esistente e nella
pipeline di resolve/plan — nessun nuovo concetto UI, entrambi si inseriscono nel flusso
già usato da `git-custom`/`git-marketplace`/`local-folder`.

Questo task deve produrre un singolo commit contenente solo le proprie modifiche.

## Steps

1. Estendere il comando/quick-pick "Add Source" in `src/ui/sourcesView.ts` per
   offrire `git-single-item` e `remote-url` accanto ai tre tipi
   esistenti, con i relativi prompt di input (URL del repository + ref opzionale per
   `git-single-item`; un singolo URL per `remote-url`).
2. Collegare entrambi i resolver nel punto in cui risiede già lo smistamento di resolve/catalog-refresh per
   `SourceType` (controllare `src/engine/index.ts` o i punti di chiamata di resolve
   in `src/ui/availableView.ts`) — estendere lo switch esistente,
   senza aggiungere un percorso di smistamento parallelo.
3. Aggiungere test di integrazione: aggiungere una sorgente di ciascun nuovo tipo attraverso lo stesso
   percorso usato dalla UI, confermare che si risolva in un `Package`/`Artifact` e che sia
   installabile tramite il motore di installazione non modificato.

## Verification

- Eseguire l'intera suite di test, lint, typecheck, build.
- Manualmente: aggiungere una sorgente `git-single-item` che punta a un repository reale a singola skill
  e una sorgente `remote-url` che punta a un URL di file raw, aggiornare e
  installare da ciascuna in Claude Code.
