# 34.3 — Cablaggio del refresh incrociato

**Depends on:** 34.1, 34.2 (integrati). Tocca anche la superficie combinata
aggiunta dall'Iniziativa 33 — avviarlo dopo che 33 è stata integrata se entrambe sono in corso,
per verificare le due insieme invece che ciascuna isolatamente.

## Perché

`specs/phase-9-spec.md` §4.1: ogni comando della sidebar che muta lo stato
aggiorna anche la barra di stato e i tree provider pertinenti. Questo è
il passaggio di integrazione che dimostra che ogni mutazione attivata dalla Dashboard
(le azioni Sources/Catalog dell'Iniziativa 33, le azioni sui suggerimenti dell'Iniziativa 34.1,
Uninstall/Update di 34.2) fa lo stesso — non si tratta di un
nuovo meccanismo, poiché l'Iniziativa 32.1 ha già cablato la callback.

## Ambito

- Verificare ogni gestore di messaggi webview aggiunto nelle Iniziative 33 e 34
  (`addSource`, `removeSource`, `exportConfig`, `exportSource`,
  `importConfig`, `installArtifact`, `installFolder`,
  `installSourceGroup`, `installRecommended`, `installRecommendation`,
  `unrecommendRecommendation`, `uninstallItem`, `updateItem`) rispetto alla
  callback di refresh incrociato dell'Iniziativa 32.1 — confermare che ciascuno di quelli che
  dovrebbero attivarla lo faccia effettivamente (alcuni metodi dei provider invocano già
  `refresh()`/`refreshCatalog()` internamente; il compito di questo task è
  confermare che anche la *barra di stato* si aggiorni, poiché è la parte che più
  probabilmente può essere stata tralasciata nei singoli task non essendone il
  focus principale).
- Correggere eventuali lacune riscontrate — ci si aspetta un piccolo insieme di aggiunte di una sola
  riga (l'invocazione della callback), non nuova logica, poiché la callback
  stessa è stata costruita in 32.1.

## Verification

- `npm run typecheck && npm run lint && npm test && npm run build` tutti
  verdi.
- Manuale, per **ciascun** messaggio nell'elenco di verifica sopra: attivarlo dalla
  Dashboard, confermare che il conteggio degli aggiornamenti/suggerimenti in sospeso nella barra di stato
  (`formatStatusBarLabel`/`formatStatusBarTooltip`,
  `src/engine/pendingCounts.ts`) si aggiorni senza dover riaprire la
  Dashboard o ricaricare la finestra, e che l'albero `Sources`/`Installed` della sidebar
  rifletta la stessa modifica.
