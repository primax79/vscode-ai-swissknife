# 35.2 — Overview tab content

**Depends on:** nothing beyond current `main`.

## Why

`getOverviewHtml()` (`src/ui/dashboard.ts:636-640`) is a literal
placeholder (`<p>Overview section placeholder</p>`) left over from
Initiative 32.2, which built the section shell but explicitly deferred
content for every section except Installed.

## Scope

- `getOverviewHtml()` becomes a real at-a-glance landing view, built from
  data `update()` already gathers (no new data-fetching methods needed —
  thread the existing `allSources`/`allManaged`/`allObserved`/
  `driftReports` and the cached recommendations group into it, same as
  `getInstalledSectionHtml`/`getRecommendationsHtml` already receive
  their data as parameters):
  - A stat-chip row reusing the existing `.stat-chip`/`.stats-ribbon` CSS
    already defined (`:` search for `stats-ribbon` in the `<style>`
    block) — Managed Installations, Updates Available, Modified Locally,
    Unmanaged Discovered (same numbers the Installed tab's ribbon shows,
    do not recompute differently), plus Pending Recommendations (from the
    cached recommended group's `pending.length`) and Sources count
    (global + project).
  - Quick-jump buttons/links to each other section (Installed, Sources &
    Catalog, Recommendations) — clicking one switches the active tab
    (reuse whatever tab-switching function 32.2 already defined
    client-side, do not duplicate it).
  - A short "recently modified/needs attention" list: up to 5 managed
    items whose drift status is `update-available`,
    `modified-and-update-available`, or `modified-locally`, each a
    clickable row that opens that item's detail panel in the Installed
    tab (reuse the existing `selectRow`/detail-panel-open client function
    rather than building a second one).
- Keep this section's own data delivery consistent with the incremental
  `postMessage` pattern established since Initiative 32.3 — do not
  reintroduce a full-HTML-reassignment path for Overview's own refresh.

## Verification

- `npm run typecheck && npm run lint && npm test && npm run build` all
  green with zero warnings.
- Manual: open the Dashboard, confirm the Overview tab shows real,
  correct numbers matching the Installed tab's own ribbon, the
  needs-attention list only shows items with real drift issues (empty
  state if none), and every quick-jump link correctly switches tabs.
