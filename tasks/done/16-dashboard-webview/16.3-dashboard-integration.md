# 16.3 — Integrazione nell'estensione e verifica

> Parte di [Webview della dashboard di gestione](plan.md) · spec: [../specs/phase-3-spec.md](../../specs/phase-3-spec.md) · richiede 16.2

## Goal

Collegare il comando `aiSwissknife.openDashboard` in `src/extension.ts` e `package.json`, aggiungendo l'icona nella barra del titolo delle viste ad albero.

Questo task deve produrre un singolo commit contenente solo le proprie modifiche.

## Steps

1. In `package.json`:
   - Aggiungere il comando `aiSwissknife.openDashboard` ("Open Dashboard", icona: `"$(dashboard)"`).
   - Aggiungere le voci di menu nella barra del titolo su `aiSwissknife.sources`, `aiSwissknife.available`, `aiSwissknife.installed`.

2. In `src/extension.ts`:
   - Registrare `aiSwissknife.openDashboard` chiamando `DashboardPanel.render(context.extensionUri)`.

3. Verificare e testare.

## Verification

- Eseguire l'intera suite di test, lint, typecheck, build.
