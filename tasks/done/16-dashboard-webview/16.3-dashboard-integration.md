# 16.3 — Extension integration & verification

> Part of [Management dashboard webview](plan.md) · spec: [../specs/phase-3-spec.md](../../specs/phase-3-spec.md) · requires 16.2

## Goal

Wire `aiSwissknife.openDashboard` command into `src/extension.ts` and `package.json`, adding title bar icon on the tree views.

This task must produce one commit containing only its changes.

## Steps

1. In `package.json`:
   - Add command `aiSwissknife.openDashboard` ("Open Dashboard", icon: `"$(dashboard)"`).
   - Add title bar menu items on `aiSwissknife.sources`, `aiSwissknife.available`, `aiSwissknife.installed`.

2. In `src/extension.ts`:
   - Register `aiSwissknife.openDashboard` calling `DashboardPanel.render(context.extensionUri)`.

3. Verify and test.

## Verification

- Run full test suite, lint, typecheck, build.
