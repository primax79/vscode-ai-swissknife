# 16.2 — UI della dashboard con ricerca, filtri e azioni

> Parte di [Webview della dashboard di gestione](plan.md) · spec: [../specs/phase-3-spec.md](../../specs/phase-3-spec.md) · richiede 16.1

## Goal

Costruire un'interfaccia HTML/CSS/JS pulita e responsiva per la webview della Dashboard usando i token del tema di VS Code.

Questo task deve produrre un singolo commit contenente solo le proprie modifiche.

## Steps

1. In `src/ui/dashboard.ts`:
   - Generare l'HTML con:
     - Barra di intestazione con titolo, campo di ricerca e pulsanti di azione ("Refresh", "Add Source", "Check Drift").
     - Schede delle metriche (Total Installed, Updates Available, Locally Modified, Unmanaged).
     - Schede di filtro per tipo (All, Skills, Agents, Commands, MCP Servers).
     - Tabella / griglia di schede degli elementi che mostra Assistant, Scope, Kind, Name, Description, Drift Status Badge e pulsanti di azione (Install / Update / Promote / Remove).

2. Aggiungere unit test in `src/ui/ui.test.ts`.

## Verification

- Eseguire l'intera suite di test, lint, typecheck, build.
