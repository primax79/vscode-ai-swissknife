# 16.1 — Pannello webview della dashboard e protocollo di messaggi

> Parte di [Webview della dashboard di gestione](plan.md) · spec: [../specs/phase-3-spec.md](../../specs/phase-3-spec.md)

## Goal

Implementare `DashboardPanel` in `src/ui/dashboard.ts` che gestisce il ciclo di vita del WebviewPanel e lo scambio di messaggi.

Questo task deve produrre un singolo commit contenente solo le proprie modifiche.

## Steps

1. Creare `src/ui/dashboard.ts`:
   - `DashboardPanel`: gestore singleton per `vscode.window.createWebviewPanel`.
   - `postState()`: raccoglie sorgenti, elementi disponibili, installazioni gestite (con report di drift) ed elementi non gestiti, e li invia alla webview.
   - Listener dei messaggi: gestisce `refresh`, `install`, `update`, `promote`, `addSource`, `removeSource`.

2. Aggiungere unit test in `src/ui/ui.test.ts`.

## Verification

- Eseguire l'intera suite di test, lint, typecheck, build.
