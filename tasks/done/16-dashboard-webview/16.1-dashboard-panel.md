# 16.1 — Dashboard webview panel & message protocol

> Part of [Management dashboard webview](plan.md) · spec: [../specs/phase-3-spec.md](../../specs/phase-3-spec.md)

## Goal

Implement `DashboardPanel` in `src/ui/dashboard.ts` that manages the WebviewPanel lifecycle and message passing.

This task must produce one commit containing only its changes.

## Steps

1. Create `src/ui/dashboard.ts`:
   - `DashboardPanel`: singleton manager for `vscode.window.createWebviewPanel`.
   - `postState()`: collects sources, available items, managed installations (with drift reports), and unmanaged items, and posts to webview.
   - Message listener: handles `refresh`, `install`, `update`, `promote`, `addSource`, `removeSource`.

2. Add unit tests in `src/ui/ui.test.ts`.

## Verification

- Run full test suite, lint, typecheck, build.
