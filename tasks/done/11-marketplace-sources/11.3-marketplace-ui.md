# 11.3 — Marketplace UI integration

> Part of [Marketplace sources resolver](plan.md) · spec: [../specs/phase-2-spec.md](../../specs/phase-2-spec.md) · requires 11.2

## Goal

Integrate `git-marketplace` sources in Sources, Available (with plugin/package grouping), and Installed tree views.

This task must produce one commit containing only its changes.

## Steps

1. In `src/ui/sourcesView.ts`:
   - Add `git-marketplace` option when adding a source.

2. In `src/ui/availableView.ts`:
   - Call `resolveGitMarketplace` when `source.type === 'git-marketplace'`.
   - Render marketplace plugins with package icons (`package`).

3. Add tests in `src/ui/ui.test.ts`.

## Verification

- Run full test suite, lint, typecheck, build.
- Verify add source, browse available, and install for marketplace sources.
