# 11.3 — Integrazione nella UI del marketplace

> Parte di [Resolver delle sorgenti marketplace](plan.md) · specifica: [../specs/phase-2-spec.md](../../specs/phase-2-spec.md) · richiede 11.2

## Goal

Integrare le sorgenti `git-marketplace` nelle viste ad albero Sources, Available (con raggruppamento per plugin/pacchetto) e Installed.

Questo task deve produrre un unico commit contenente solo le proprie modifiche.

## Steps

1. In `src/ui/sourcesView.ts`:
   - Aggiungere l'opzione `git-marketplace` durante l'aggiunta di una sorgente.

2. In `src/ui/availableView.ts`:
   - Chiamare `resolveGitMarketplace` quando `source.type === 'git-marketplace'`.
   - Renderizzare i plugin del marketplace con l'icona del pacchetto (`package`).

3. Aggiungere test in `src/ui/ui.test.ts`.

## Verification

- Eseguire l'intera suite di test, lint, typecheck e build.
- Verificare l'aggiunta della sorgente, la navigazione degli elementi disponibili e l'installazione per le sorgenti marketplace.
