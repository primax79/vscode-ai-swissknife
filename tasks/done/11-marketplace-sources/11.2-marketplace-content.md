# 11.2 — Risoluzione del contenuto marketplace e motore di installazione

> Parte di [Resolver delle sorgenti marketplace](plan.md) · specifica: [../specs/phase-2-spec.md](../../specs/phase-2-spec.md) · richiede 11.1

## Goal

Implementare `resolveArtifactContent` per le sorgenti `git-marketplace` su tutti i tipi di artefatto (`skill`, `agent`, `command`, `mcp-server`) e collegarlo in `planInstall`.

Questo task deve produrre un unico commit contenente solo le proprie modifiche.

## Steps

1. In `src/sources/gitMarketplace.ts`:
   - Implementare `resolveArtifactContent(source: Source, pkg: Package, artifact: Artifact, opts?: GitCustomResolveOptions): Promise<ResolvedArtifact<...>>`.
   - Acquisire il lock della directory di cache tramite `gitMarketplaceMutex`.
   - Eseguire il checkout di `pkg.version.commit`.
   - Risolvere il contenuto dell'artefatto in base ad `artifact.kind`.

2. Collegare `resolveGitMarketplace` e `resolveArtifactContent` in `src/engine/plan.ts`.

3. Aggiungere unit test per la risoluzione del contenuto e l'installazione degli artefatti marketplace in `src/engine/install.test.ts`.

## Verification

- Eseguire l'intera suite di test, lint, typecheck e build.
- Testare pianificazione e applicazione per una skill, un agent, un command e un server MCP risolti da una sorgente marketplace.
