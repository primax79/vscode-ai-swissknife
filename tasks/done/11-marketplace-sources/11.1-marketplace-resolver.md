# 11.1 — Resolver dei manifest marketplace per Claude e Kilo

> Parte di [Resolver delle sorgenti marketplace](plan.md) · specifica: [../specs/phase-2-spec.md](../../specs/phase-2-spec.md)

## Goal

Implementare `resolveGitMarketplace` in `src/sources/gitMarketplace.ts` che clona/aggiorna i repository git marketplace, effettua il parsing di `.claude-plugin/marketplace.json` o `marketplace-skills.json` e rileva skill, agent, command e MCP all'interno di ciascun plugin registrato.

Questo task deve produrre un unico commit contenente solo le proprie modifiche.

## Steps

1. Creare `src/sources/gitMarketplace.ts`:
   - `gitMarketplaceMutex`: KeyedMutex per la sincronizzazione della cache.
   - `resolveGitMarketplace(source: Source, opts?: GitCustomResolveOptions): Promise<SourceResolution>`.
   - Clona/aggiorna il repository ed esegue il checkout del ref richiesto (commit/tag/branch/default).
   - Rileva il manifest del marketplace:
     - `.claude-plugin/marketplace.json` oppure `marketplace.json` (formato plugin di Claude).
     - `marketplace-skills.json` (formato feed di Kilo).
   - Per ogni voce di plugin nel manifest:
     - Legge la directory del plugin o il percorso di destinazione.
     - Rileva skill, agent, command e server MCP all'interno della cartella del plugin.
     - Costruisce gli elementi `Package` e raccoglie le `DetectionDiagnostic`.

2. Aggiungere unit test in `src/sources/gitMarketplace.test.ts`.

## Verification

- Eseguire l'intera suite di test, lint, typecheck e build.
- Testare la risoluzione di un repository marketplace con più plugin e artefatti annidati.
