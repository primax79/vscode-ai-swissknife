# 10.3 — Discovery MCP e integrazione nella UI

> Parte di [Supporto agli artefatti MCP-server](plan.md) · specifica: [../specs/phase-2-spec.md](../../specs/phase-2-spec.md) · richiede 10.2

## Goal

Rilevare le definizioni dei server MCP nei resolver `localFolder` e `gitCustom`, visualizzarle nelle viste ad albero Available e Installed con l'icona della spina (`plug`) e abilitare l'installazione singola e in batch.

Questo task deve produrre un unico commit contenente solo le proprie modifiche.

## Steps

1. In `src/sources/detect.ts`:
   - Aggiungere `findMcpDefinitions(rootDir: string): Promise<{ mcpServers: DetectedMcpServer[]; diagnostics: DetectionDiagnostic[]; }>`.
   - Scansionare `.mcp.json`, `mcp.json` o i file JSON nella directory `mcps/`.

2. In `src/sources/localFolder.ts` e `src/sources/gitCustom.ts`:
   - Mappare i server MCP rilevati in `Package` con `Artifact (kind: 'mcp-server')`.
   - Implementare `resolveArtifactContent` per `artifact.kind === 'mcp-server'`.

3. In `src/ui/availableView.ts` e `src/ui/installedView.ts`:
   - Renderizzare i server MCP con `new vscode.ThemeIcon('plug')`.
   - Visualizzare il tipo `mcp-server` nelle descrizioni e nei tooltip.

4. Aggiungere unit test e fixture.

## Verification

- Eseguire l'intera suite di test, lint, typecheck e build.
- Verificare discovery, anteprima e installazione dei server MCP da sorgenti locali e Git.
