# 10.3 — MCP discovery & UI integration

> Part of [MCP-server artifact support](plan.md) · spec: [../specs/phase-2-spec.md](../../specs/phase-2-spec.md) · requires 10.2

## Goal

Detect MCP server definitions in `localFolder` and `gitCustom` resolvers, display them in Available and Installed tree views with plug icon (`plug`), and enable single and batch installation.

This task must produce one commit containing only its changes.

## Steps

1. In `src/sources/detect.ts`:
   - Add `findMcpDefinitions(rootDir: string): Promise<{ mcpServers: DetectedMcpServer[]; diagnostics: DetectionDiagnostic[]; }>`.
   - Scan for `.mcp.json`, `mcp.json`, or JSON files in `mcps/` directory.

2. In `src/sources/localFolder.ts` and `src/sources/gitCustom.ts`:
   - Map detected MCP servers to `Package` with `Artifact (kind: 'mcp-server')`.
   - Implement `resolveArtifactContent` for `artifact.kind === 'mcp-server'`.

3. In `src/ui/availableView.ts` and `src/ui/installedView.ts`:
   - Render MCP servers with `new vscode.ThemeIcon('plug')`.
   - Display kind: `mcp-server` in descriptions and tooltips.

4. Add unit tests and fixtures.

## Verification

- Run full test suite, lint, typecheck, build.
- Verify discovery, preview, and install of MCP servers from local and Git sources.
