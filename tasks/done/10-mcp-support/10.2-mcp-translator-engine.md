# 10.2 — Traduttore MCP e motore di installazione

> Parte di [Supporto agli artefatti MCP-server](plan.md) · specifica: [../specs/phase-2-spec.md](../../specs/phase-2-spec.md) · richiede 10.1

## Goal

Implementare `translateMcpServer`, `canonicalMcpServerHash` ed estendere `planInstall` / `applyInstall` per gestire `kind: 'mcp-server'`.

Questo task deve produrre un unico commit contenente solo le proprie modifiche.

## Steps

1. Creare `src/translator/mcp.ts`:
   - `translateMcpServer(source: CanonicalMcpServer, targetAssistant: AssistantId): TranslationResult<CanonicalMcpServer>`

2. In `src/adapters/codec.ts`:
   - Implementare `canonicalMcpServerHash(mcp: CanonicalMcpServer): string` (sha256 deterministico).

3. Estendere `src/engine/types.ts`:
   - Aggiungere `kind: 'mcp-server'` con `content: CanonicalMcpServer` a `PreparedInstall`.

4. Estendere `src/engine/plan.ts` e `src/engine/apply.ts`:
   - Gestire `artifact.kind === 'mcp-server'`.
   - In `planInstall`: leggere il file di configurazione di destinazione e controllare se l'ID del server è già presente (conflitto).
   - In `applyInstall`: eseguire il backup del file di configurazione, fare il merge della configurazione del server nell'oggetto JSON, verificare e persistere lo stato in `state.json`.

5. Aggiungere test in `src/translator/mcp.test.ts` e `src/engine/install.test.ts`.

## Verification

- Eseguire l'intera suite di test, lint, typecheck e build.
- Testare l'installazione atomica di un server MCP e la preservazione delle configurazioni esistenti.
- Testare il rollback in caso di fallimento della verifica.
