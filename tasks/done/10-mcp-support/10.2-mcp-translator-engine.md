# 10.2 — MCP translator & install engine

> Part of [MCP-server artifact support](plan.md) · spec: [../specs/phase-2-spec.md](../../specs/phase-2-spec.md) · requires 10.1

## Goal

Implement `translateMcpServer`, `canonicalMcpServerHash`, and extend `planInstall` / `applyInstall` to handle `kind: 'mcp-server'`.

This task must produce one commit containing only its changes.

## Steps

1. Create `src/translator/mcp.ts`:
   - `translateMcpServer(source: CanonicalMcpServer, targetAssistant: AssistantId): TranslationResult<CanonicalMcpServer>`

2. In `src/adapters/codec.ts`:
   - Implement `canonicalMcpServerHash(mcp: CanonicalMcpServer): string` (deterministic sha256).

3. Extend `src/engine/types.ts`:
   - Add `kind: 'mcp-server'` with `content: CanonicalMcpServer` to `PreparedInstall`.

4. Extend `src/engine/plan.ts` and `src/engine/apply.ts`:
   - Handle `artifact.kind === 'mcp-server'`.
   - In `planInstall`: read target config file, inspect if server ID is already present (conflict).
   - In `applyInstall`: backup config file, merge server configuration into JSON object, verify, and persist state in `state.json`.

5. Add tests in `src/translator/mcp.test.ts` and `src/engine/install.test.ts`.

## Verification

- Run full test suite, lint, typecheck, build.
- Test atomic installation of an MCP server and preservation of existing configurations.
- Test rollback on verification failure.
