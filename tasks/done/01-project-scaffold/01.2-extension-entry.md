# 01.2 — Extension entry point + activation

> Part of [Project scaffold](plan.md) · spec: [../specs/foundations.md](../../specs/foundations.md)

**Goal**: a minimal `src/extension.ts` that activates cleanly in the
Extension Development Host, with the folder layout later initiatives will
fill in.

**Grounding**: `references/agent-hub/src/extension.ts` for the general
shape of a VSCode extension entry point (`activate(context)`/
`deactivate()`), but agent-hub's version wires up its DB/services/webviews
— none of that exists yet here, so this task's version is much smaller.

Steps:

1. Create the folder layout (empty `.gitkeep`-style placeholders are fine
   where a later initiative fills a folder — don't create speculative
   files beyond what's listed):
   - `src/extension.ts` — the entry point (below).
   - `src/domain/` — empty, initiative 02 fills it.
   - `src/adapters/` — empty, initiative 03 fills it.
   - `src/sources/` — empty, initiative 04 fills it.
2. Write `src/extension.ts`:
   ```ts
   import * as vscode from 'vscode';

   export function activate(context: vscode.ExtensionContext) {
     console.log('AI Swissknife is now active.');
   }

   export function deactivate() {}
   ```
   Nothing more — no commands, no views. Later initiatives extend this
   file; don't pre-register placeholder commands or views that
   initiative 07 will have to remove or rename.
3. Build: `npm run build`. Confirm `dist/extension.js` is produced with no
   esbuild errors.
4. Launch the Extension Development Host (`F5` in VSCode, or
   `code --extensionDevelopmentPath=<repo>` if scripting it) and confirm,
   via the Debug Console or the Developer Tools console of the new
   window, that `AI Swissknife is now active.` is logged — i.e. the
   extension actually activates, not just that it compiles.

**Verification**: `npm run build` succeeds; `dist/extension.js` exists;
the activation log line appears in a real Extension Development Host run
(not just "the code looks like it would log this" — actually launch it).
One commit containing `src/extension.ts` and the empty folder
placeholders — nothing else.
