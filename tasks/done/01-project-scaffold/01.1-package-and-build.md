# 01.1 — package.json + build tooling

> Part of [Project scaffold](plan.md) · spec: [../specs/foundations.md](../../specs/foundations.md)

**Goal**: create `package.json`, `tsconfig.json`, and an esbuild-based
build script so the extension can compile, with no source files yet beyond
what task 01.2 adds.

**Grounding** (read these two files first, they're the real precedent to
follow, in this same repo's `references/` directory — don't invent a
different shape):

- `references/agent-hub/package.json`
- `references/agent-hub/tsconfig.json`
- `references/agent-hub/esbuild.config.js`

Steps:

1. Create `package.json` at the repo root, modeled on
   `references/agent-hub/package.json` but adapted:
   - `"name": "ai-swissknife"`, `"displayName": "AI Swissknife"`,
     `"description": "Cross-assistant marketplace and management for
     custom skill/agent/mcp/rule repositories (Claude Code, Kilo Code, and
     more)."`, `"version": "0.0.1"`, `"publisher": "TODO-set-before-publish"`.
   - `"repository": {"type": "git", "url":
     "git@github.com:primax79/vscode-ai-swissknife.git"}`.
   - `"engines": {"vscode": "^1.95.0"}` (same floor as `agent-hub`, a real
     recent-enough baseline).
   - `"categories": ["AI", "Other"]`.
   - `"activationEvents": ["onStartupFinished"]` — no `onUri` (that was
     agent-hub-specific, not needed here).
   - `"main": "./dist/extension.js"`.
   - `"contributes"`: leave `"commands": []` and no `"views"`/
     `"viewsContainers"` yet — task 07 (minimal UI, a later initiative)
     adds those. Do not pre-declare view ids here; an empty `contributes`
     block (or omitted) is correct for this task.
   - `"scripts"`: `"vscode:prepublish": "npm run build"`, `"build": "node
     esbuild.config.js"`, `"watch": "node esbuild.config.js --watch"`,
     `"typecheck": "tsc --noEmit"`, `"lint": "eslint src --ext ts"` (task
     01.3 adds the eslint config this depends on — it's fine for the
     script to exist before the config, `npm run lint` just isn't
     expected to pass until 01.3 lands).
   - `"devDependencies"`: `@types/node`, `@types/vscode` (pin to the same
     `^1.95.0`-compatible version `agent-hub` uses), `@types/mocha`,
     `@vscode/test-electron`, `esbuild`, `typescript`. **Do not** include
     `better-sqlite3`, `@electron/rebuild`, `@vscode/webview-ui-toolkit`,
     `zod`, `semver` — none are needed for this slice (no local DB, no
     webview, no marketplace-manifest schema validation yet).
   - No `"postinstall"` script (that was specifically for
     `better-sqlite3`'s native rebuild in `agent-hub`, not applicable
     here).
2. Create `tsconfig.json` at the repo root, same shape as
   `references/agent-hub/tsconfig.json` (`module: commonjs`, `target:
   ES2020`, `outDir: out`, `rootDir: src`, `strict: true`,
   `esModuleInterop: true`, `skipLibCheck: true`,
   `forceConsistentCasingInFileNames: true`, `resolveJsonModule: true`,
   `moduleResolution: node`), `"include": ["src/**/*"]`, `"exclude":
   ["node_modules", ".vscode-test"]` (no `src/webview/**/*` exclusion —
   there's no webview in this slice).
3. Create `esbuild.config.js` at the repo root, modeled on
   `references/agent-hub/esbuild.config.js`'s `extensionConfig` block
   only (entry `./src/extension.ts`, bundle, outfile
   `./dist/extension.js`, `external: ['vscode']`, `format: 'cjs'`,
   `platform: 'node'`, `target: 'node18'`, sourcemap on, minify when not
   watching). **Omit** the `webviewConfig` block entirely — there is no
   webview entry point yet.
4. Run `npm install` at the repo root to generate `package-lock.json` and
   populate `node_modules/`.
5. Add `node_modules/`, `out/`, `dist/`, `*.vsix` to `.gitignore`
   (append to the existing file, which currently only has `references`
   — don't remove that line).

**Verification**: `npm install` completes with no errors; `node
esbuild.config.js` fails with a clear "entry point not found" error at
this stage (expected — `src/extension.ts` doesn't exist until task 01.2)
rather than a config/syntax error. This is one commit containing
`package.json`, `package-lock.json`, `tsconfig.json`, `esbuild.config.js`,
and the `.gitignore` addition — nothing else.
