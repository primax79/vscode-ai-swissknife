# 12.1 — Implementazione di CopilotAdapter

> Parte di [Adapter GitHub Copilot](plan.md) · specifica: [../specs/phase-2-spec.md](../../specs/phase-2-spec.md)

## Goal

Implementare `CopilotAdapter` supportando le convenzioni di GitHub Copilot in VS Code:
- Skill: `.github/skills/<name>/SKILL.md` (progetto) o `~/.copilot/skills/<name>/SKILL.md` (globale).
- Agent: `.github/agents/<name>.agent.md` (progetto) o `~/.copilot/agents/<name>.agent.md` (globale).
- Prompt / Command: `.github/prompts/<name>.prompt.md` (progetto) o `~/.copilot/prompts/<name>.prompt.md` (globale).
- Server MCP: `.vscode/mcp.json` (progetto) o `~/.copilot/mcp.json` (globale).
- Regole: `.github/copilot-instructions.md` (progetto) o `~/.copilot/copilot-instructions.md` (globale).

Questo task deve produrre un unico commit contenente solo le proprie modifiche.

## Steps

1. Creare `src/adapters/copilot.ts`:
   - `CopilotAdapter implements Adapter`.
   - `assistant: 'github-copilot'`.
   - Implementare `skillDir`, `skillPath`, `readSkill`, `writeSkill`, `listSkills`.
   - Implementare `agentPath`, `readAgent`, `writeAgent`, `listAgents`.
   - Implementare `commandPath`, `readCommand`, `writeCommand`, `listCommands`.
   - Implementare `mcpConfigPath`, `readMcpServer`, `writeMcpServer`, `listMcpServers`.
   - Implementare `rulePath`, `readRule`, `writeRule`.

2. Aggiungere unit test in `src/adapters/copilot.test.ts`.

## Verification

- Eseguire l'intera suite di test, lint, typecheck e build.
- Testare lettura e scrittura round-trip di skill, agent, prompt, server MCP e istruzioni sotto i percorsi di GitHub Copilot.
