# 12.1 — CopilotAdapter implementation

> Part of [GitHub Copilot adapter](plan.md) · spec: [../specs/phase-2-spec.md](../../specs/phase-2-spec.md)

## Goal

Implement `CopilotAdapter` supporting GitHub Copilot conventions in VS Code:
- Skills: `.github/skills/<name>/SKILL.md` (project) or `~/.copilot/skills/<name>/SKILL.md` (global).
- Agents: `.github/agents/<name>.agent.md` (project) or `~/.copilot/agents/<name>.agent.md` (global).
- Prompts / Commands: `.github/prompts/<name>.prompt.md` (project) or `~/.copilot/prompts/<name>.prompt.md` (global).
- MCP Servers: `.vscode/mcp.json` (project) or `~/.copilot/mcp.json` (global).
- Rules: `.github/copilot-instructions.md` (project) or `~/.copilot/copilot-instructions.md` (global).

This task must produce one commit containing only its changes.

## Steps

1. Create `src/adapters/copilot.ts`:
   - `CopilotAdapter implements Adapter`.
   - `assistant: 'github-copilot'`.
   - Implement `skillDir`, `skillPath`, `readSkill`, `writeSkill`, `listSkills`.
   - Implement `agentPath`, `readAgent`, `writeAgent`, `listAgents`.
   - Implement `commandPath`, `readCommand`, `writeCommand`, `listCommands`.
   - Implement `mcpConfigPath`, `readMcpServer`, `writeMcpServer`, `listMcpServers`.
   - Implement `rulePath`, `readRule`, `writeRule`.

2. Add unit tests in `src/adapters/copilot.test.ts`.

## Verification

- Run full test suite, lint, typecheck, build.
- Test round-trip reading and writing of skills, agents, prompts, MCP servers, and instructions under GitHub Copilot paths.
