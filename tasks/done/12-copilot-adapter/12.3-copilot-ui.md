# 12.3 — Integrazione nel motore e nella UI per GitHub Copilot

> Parte di [Adapter GitHub Copilot](plan.md) · specifica: [../specs/phase-2-spec.md](../../specs/phase-2-spec.md) · richiede 12.2

## Goal

Esporre GitHub Copilot (`github-copilot`) nella UI di selezione dell'assistente e supportare l'installazione end-to-end di tutti i tipi di artefatto nei percorsi di Copilot.

Questo task deve produrre un unico commit contenente solo le proprie modifiche.

## Steps

1. In `src/engine/apply.ts`:
   - Istanziare e smistare verso `CopilotAdapter` quando `targetAssistant === 'github-copilot'`.

2. In `src/ui/availableView.ts`:
   - Aggiungere `github-copilot` al quick-pick di selezione dell'assistente.
   - Collegare `copilotAdapter`.

3. Aggiornare `src/engine/install.test.ts` e `src/ui/ui.test.ts`.

## Verification

- Eseguire l'intera suite di test, lint, typecheck e build.
- Testare l'installazione end-to-end di skill, agent, command e server MCP nei percorsi di GitHub Copilot.
