# 12.2 — Matrici di traduzione per Copilot

> Parte di [Adapter GitHub Copilot](plan.md) · specifica: [../specs/phase-2-spec.md](../../specs/phase-2-spec.md) · richiede 12.1

## Goal

Abilitare `github-copilot` come assistente di destinazione di prima classe in tutti i moduli di traduzione:
- `translateSkill` (senza perdita)
- `translateAgent` (mappa l'array dei tool / il modello)
- `translateCommand` (formatta il markdown del prompt)
- `translateMcpServer` (configurazione stdio/sse/http)

Questo task deve produrre un unico commit contenente solo le proprie modifiche.

## Steps

1. Aggiornare `src/translator/skill.ts`:
   - Aggiungere `targetAssistant === 'github-copilot'` al ramo di ritorno senza perdita.

2. Aggiornare `src/translator/agent.ts`:
   - Aggiungere `targetAssistant === 'github-copilot'` mappando tool e modello.

3. Aggiornare `src/translator/command.ts`:
   - Aggiungere `targetAssistant === 'github-copilot'` mappando descrizione, modello e corpo.

4. Aggiornare `src/translator/mcp.ts`:
   - Aggiungere `targetAssistant === 'github-copilot'` mappando la configurazione del server.

5. Aggiornare i test in `skill.test.ts`, `agent.test.ts`, `command.test.ts` e `mcp.test.ts`.

## Verification

- Eseguire l'intera suite di test, lint, typecheck e build.
- Testare la traduzione di skill, agent, command e server MCP aventi `github-copilot` come destinazione.
