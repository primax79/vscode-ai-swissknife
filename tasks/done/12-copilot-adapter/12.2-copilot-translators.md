# 12.2 — Copilot translation matrices

> Part of [GitHub Copilot adapter](plan.md) · spec: [../specs/phase-2-spec.md](../../specs/phase-2-spec.md) · requires 12.1

## Goal

Enable `github-copilot` as a first-class target assistant in all translation modules:
- `translateSkill` (lossless)
- `translateAgent` (maps tools array / model)
- `translateCommand` (formats prompt markdown)
- `translateMcpServer` (stdio/sse/http config)

This task must produce one commit containing only its changes.

## Steps

1. Update `src/translator/skill.ts`:
   - Add `targetAssistant === 'github-copilot'` to lossless return branch.

2. Update `src/translator/agent.ts`:
   - Add `targetAssistant === 'github-copilot'` mapping tools and model.

3. Update `src/translator/command.ts`:
   - Add `targetAssistant === 'github-copilot'` mapping description, model, body.

4. Update `src/translator/mcp.ts`:
   - Add `targetAssistant === 'github-copilot'` mapping server config.

5. Update tests in `skill.test.ts`, `agent.test.ts`, `command.test.ts`, and `mcp.test.ts`.

## Verification

- Run full test suite, lint, typecheck, build.
- Test translation of skills, agents, commands, and MCP servers targeting `github-copilot`.
