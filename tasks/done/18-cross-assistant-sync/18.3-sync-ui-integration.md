# 18.3 — Azione UI "Copy to..."

> Parte di [Sincronizzazione tra assistenti](plan.md) · spec: [../specs/phase-4-spec.md](../../specs/phase-4-spec.md) §4

## Goal

Esporre la sincronizzazione nella UI: un'azione "Copy to..." su un elemento installato (vista
Installed e Dashboard) che consente all'utente di scegliere assistente + scope di destinazione
(+ percorso del progetto quando lo scope è `project`), esegue `planSync`, mostra lo stesso
tipo di anteprima già mostrato dalla pipeline di installazione dal marketplace e applica le modifiche
alla conferma. Aggiungere una variante batch per la selezione multipla.

Questo task deve produrre un singolo commit contenente solo le proprie modifiche.

## Steps

1. Aggiungere un comando "Copy to..." (`aiSwissknife.syncArtifact`) invocabile dalle
   azioni inline di `src/ui/installedView.ts` e dalla UI webview di
   `src/ui/dashboard.ts`.
2. Selettore di destinazione: quick-pick dell'assistente (escludendo l'assistente di origine),
   quick-pick dello scope (`global`/`project`) e — quando è `project` — lo stesso
   selettore di cartella del workspace già usato altrove (`src/ui/workspacePicker.ts`).
3. Mostrare il piano/anteprima (riutilizzare lo stesso rendering dell'anteprima già presente
   nella pipeline di installazione per `SupportedInstallPlan`/diagnostiche), poi applicare
   tramite l'esistente `applyInstall` alla conferma.
4. Variante batch: selezione multipla nella vista Installed → stesso selettore di destinazione una sola volta
   → risoluzione dei conflitti per singolo elemento da 18.2 → messaggio di esito aggregato
   (rispettando lo stile di esito aggregato dell'installazione batch già presente in
   `src/ui/availableView.ts`).

## Verification

- Eseguire l'intera suite di test, lint, typecheck, build.
- Manualmente: sincronizzare un agent installato su Kilo nello scope di progetto di Claude Code,
  confermare che il file tradotto appaia nel formato corretto e che la
  `ManagedInstallation` registri la provenienza della sincronizzazione; sincronizzare un batch di 2+
  elementi con un conflitto intenzionale e confermare che skip/overwrite per elemento
  si comporti come scelto.
