# 13.2 — Upstream update checker

> Part of [Drift & update detection](plan.md) · spec: [../specs/phase-3-spec.md](../../specs/phase-3-spec.md) · requires 13.1

## Goal

Implement upstream update detection by resolving the latest artifact version from its original `Source` and comparing with the installed and local disk hashes.

This task must produce one commit containing only its changes.

## Steps

1. In `src/engine/drift.ts`:
   - Add `checkForUpstreamUpdate(installation: ManagedInstallation, source: Source, homeRoot?: string): Promise<DriftReport>`.
   - Resolves latest artifact content from `source`.
   - Computes upstream `sourceHash`.
   - Compares:
     - If local disk modified AND upstream source has newer hash: `status: 'modified-and-update-available'`.
     - If local disk untouched AND upstream source has newer hash: `status: 'update-available'`.
     - If local disk untouched AND upstream hash matches: `status: 'up-to-date'`.

2. Add unit tests in `src/engine/drift.test.ts`.

## Verification

- Run full test suite, lint, typecheck, build.
- Test update detection with new commits in Git sources and modified local files.
