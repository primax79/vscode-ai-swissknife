# 13.2 — Verificatore di aggiornamenti upstream

> Parte di [Rilevamento di drift e aggiornamenti](plan.md) · spec: [../specs/phase-3-spec.md](../../specs/phase-3-spec.md) · richiede 13.1

## Goal

Implementare il rilevamento degli aggiornamenti upstream risolvendo l'ultima versione dell'artefatto dalla sua `Source` originale e confrontandola con gli hash installati e su disco locale.

Questo task deve produrre un singolo commit contenente solo le proprie modifiche.

## Steps

1. In `src/engine/drift.ts`:
   - Aggiungere `checkForUpstreamUpdate(installation: ManagedInstallation, source: Source, homeRoot?: string): Promise<DriftReport>`.
   - Risolve l'ultimo contenuto dell'artefatto da `source`.
   - Calcola `sourceHash` upstream.
   - Confronta:
     - Se il disco locale è modificato E la sorgente upstream ha un hash più recente: `status: 'modified-and-update-available'`.
     - Se il disco locale è intatto E la sorgente upstream ha un hash più recente: `status: 'update-available'`.
     - Se il disco locale è intatto E l'hash upstream coincide: `status: 'up-to-date'`.

2. Aggiungere unit test in `src/engine/drift.test.ts`.

## Verification

- Eseguire l'intera suite di test, lint, typecheck, build.
- Testare il rilevamento degli aggiornamenti con nuovi commit nelle sorgenti Git e file locali modificati.
