# 13.1 — Motore di analisi del drift

> Parte di [Rilevamento di drift e aggiornamenti](plan.md) · spec: [../specs/phase-3-spec.md](../../specs/phase-3-spec.md)

## Goal

Implementare `analyzeDrift` in `src/engine/drift.ts` che confronta una `ManagedInstallation` con lo stato corrente su disco.

Questo task deve produrre un singolo commit contenente solo le proprie modifiche.

## Steps

1. Definire `DriftStatus` e `DriftReport` in `src/engine/types.ts`:
```ts
export type DriftStatus =
  | 'up-to-date'
  | 'modified-locally'
  | 'update-available'
  | 'modified-and-update-available'
  | 'missing-on-disk';

export interface DriftReport {
  installation: ManagedInstallation;
  status: DriftStatus;
  diskHash?: string;
  sourceHash?: string;
  details?: string;
}
```

2. Creare `src/engine/drift.ts`:
   - `analyzeLocalDrift(installation: ManagedInstallation, homeRoot?: string): Promise<DriftReport>`
   - Smista in base a `installation.kind`:
     - `skill`: verifica l'esistenza della directory con `lstat`, legge la skill tramite `readSkill(installation.path)`, calcola `canonicalSkillHash`, confronta con `installation.contentHash`.
     - `agent`: verifica l'esistenza del file, legge l'agent tramite `readAgent`, calcola `canonicalAgentHash`, confronta con `installation.contentHash`.
     - `command`: verifica l'esistenza del file, legge il command tramite `readCommand`, calcola `canonicalCommandHash`, confronta con `installation.contentHash`.
     - `mcp-server`: legge il file di configurazione di destinazione tramite `readMcpServer`, calcola `canonicalMcpServerHash`, confronta con `installation.contentHash`.
   - Se il percorso manca / è stato eliminato: restituisce `status: 'missing-on-disk'`.
   - Se l'hash differisce: restituisce `status: 'modified-locally'`.
   - Se l'hash coincide: restituisce `status: 'up-to-date'`.

3. Aggiungere unit test in `src/engine/drift.test.ts`.

## Verification

- Eseguire l'intera suite di test, lint, typecheck, build.
- Testare l'analisi del drift per skill, agent, command e server MCP intatti, modificati localmente ed eliminati.
