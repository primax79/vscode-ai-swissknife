2. `planUpdateAll({ installations, sources, reports, filter?, includeModified? })` where `filter` = `{ scope?, assistant?, sourceId?, kind? }`:
   - buckets: `toUpdate` (status `update-available`; plus `modified-and-update-available` and `modified-locally`-with-update only when `includeModified`), `skippedModified` (listed with their status), `cannotUpdate` (no `sourceId`, source not in manifest, resolution failed, `missing-on-disk`, plan unsupported) each with a reason;

   - returns the buckets plus the `PreparedInstall` of each `toUpdate` item. Never writes anything.

One failing item never stops the rest.
