# CLI wishlist from the skills-maintainer session vs what ai-swissknife has or plans

Source: `../../tasks/tooling/notes/swissknife-cli-wishlist-2026-10-08.md` (workspace task T012, session `ai-coding-tools-1e`, relayed 2026-10-08; 12 items, goal: the extension replaces `kilo-plugin-manager` / `plugin_manager.py`). Compared against the code as of `main` 0.4.0 and initiatives 38-47. Status key: **HAVE** (in the code today), **PLAN** (in a written initiative), **MISSING** (not planned), **N/A** (out of scope for ai-swissknife, reason given).

Vocabulary mapping: their `claude|kilo` = our assistants `claude-code|kilo-code`; their scopes `user|project|workspace:<path>` = our `global|project` + `--workspace <path>` (user-facing "Global" / "Workspace"); their `--dry-run` = our **plan-only default** (46: write commands without `--write` print the plan and change nothing; with `--write` they apply). Non-interactive + JSON on stdout + non-zero exit: already the 46 contract.

| # | Wish | Status | Detail |

| 1 | update item / `--all`, per client and scope, detect by content/commit | **HAVE** (detection) + **PLAN** (command) | Drift compares the canonical **content hash** of the translated source artifact with the installed one (`drift.ts`), never the manifest version, so the "already latest" trap does not exist here. Update all = initiative 47; CLI `update --all` in 46.4. **MISSING**: `update <item>` (single) in the CLI, the report "old commit -> new commit, files changed" (47 returns outcomes, not commits/changed files), per-client selector wording. |

| 3 | list / status with provenance | **HAVE** (data) + **PLAN** (CLI) | `scanInstalledInventory` gives source, match, state; CLI `installed` / `updates` in 46.1. **MISSING**: link-vs-copy flag (the adapters read with `lstat` and skip symlinks, so linked items are currently invisible rather than flagged), broken links, **orphan** (item deleted from its source: the engine only reports `missing-on-disk`, not "gone from source"), "installed twice" (doctor, below). |

## Proposal

New initiative **48 — Maintainer features for the CLI** (outline only, nothing specified in full until the owner decides): 48.1 multi-root scanning with ignore rules (item 5), 48.2 provenance and orphan/link flags in `installed` (item 3), 48.3 shadowing classification with history lookup (item 4, plus the guard of item 12), 48.4 doctor checks (item 7) on top of study B4, 48.5 `replaces` (item 6, after a decision on its format), 48.6 contribute-back (item 8), 48.7 sources fetch/behind/pin (item 10). Items 9 (recorded transforms) and 11 stay out until designed / re-homed.
